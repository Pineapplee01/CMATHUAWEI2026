# 复杂场景下多模态情感预测

> 面向竞赛论文与附件交付的可复现多模态情感预测研究项目。

## Problem

文本、语音和视觉信号的时间尺度不同，现实采集还会出现连续时间段的局部模态缺失，模型输出也需要给出可复核的判断依据。题目要求依次解决时序对齐、缺失鲁棒预测和可解释预测。

## Solution

使用统一的数据契约和可配置的对齐/非对齐输入适配器，把三个题目问题组织为共享核心上的独立任务域，并将预测、解释、评估和提交文件作为可追踪产物导出。

## Target Users

| Persona | Needs | Pain Points |
| --- | --- | --- |
| 建模成员 | 可替换模型和统一实验入口 | 数据格式、指标和结果文件容易不一致 |
| 论文成员 | 可追溯的事实、图表和方法记录 | 工程结论难以转成论文证据 |
| 复核者 | 一键检查数据契约和运行环境 | 原始数据大、路径和版本容易混乱 |

## Core Features

| Feature | Status | Description |
| --- | --- | --- |
| 项目上下文 | implemented | conductor 文档记录目标、技术栈和工作流 |
| 数据契约 | implemented | 统一样本、掩码、标签、预测和证据对象 |
| 数据探针 | implemented | 检查附件字段、形状、标签和专项测试文件 |
| 问题1任务域 | scaffolded | 预留特征提取与时序对齐接口 |
| 问题2任务域 | scaffolded | 预留缺失模拟与鲁棒预测接口 |
| 问题3任务域 | scaffolded | 预留贡献计算与证据映射接口 |

## Roadmap

- **Phase 1**：项目初始化、数据镜像、契约和术语约束。
- **Phase 2**：问题1特征提取、对齐和100条样本清单。
- **Phase 3**：问题2缺失鲁棒模型、消融和附件3导出。
- **Phase 4**：问题3解释模型、证据卡和附件4导出。
- **Phase 5**：论文、附件整理和提交前审计。
