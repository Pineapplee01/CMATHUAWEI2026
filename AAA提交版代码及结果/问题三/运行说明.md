# 问题三运行说明

所有命令在项目根目录 `CPMCM` 执行。运行前按 [共用环境与模型说明](../模型下载与使用说明.md) 配置环境和模型。

## 输入与配置

本问使用问题二的固定模型，不重新训练。保留提交目录中的 `问题二/代码` 和 `问题三/代码`，本问辅助功能位于 `代码/q3_utils.py`。

附件4的两版原始 PKL 分别放在以下目录，每版20条，无需预先标准化：

```text
AAAdata/Appendix_4/对齐版本/
AAAdata/Appendix_4/未对齐版本/
```

同时需要 `AAAdata/Appendix_2/对齐版本` 和 `AAAdata/Appendix_2/未对齐版本` 中的 `scaler_params.npz`、`test.npz`；程序在专项预测后还会评估附件2测试集。

配置分别为 `代码/config_aligned.json`、`代码/config_unaligned.json`。`checkpoint` 指定权重，`appendix4` 指定专项数据，`results` 指定输出目录。

## 运行

```bash
python "AAA提交版代码及结果/问题三/代码/aligned.py" --device cuda:0
python "AAA提交版代码及结果/问题三/代码/unaligned.py" --device cuda:0
```

`--device cpu` 使用 CPU；`--config 配置文件.json` 使用其他配置。`--smoke` 只处理附件4首条样本，但仍评估附件2测试集并写入结果。

## 输出

默认生成 `主要结果/对齐版本_附件4_预测与解释结果.csv` 和 `主要结果/未对齐版本_附件4_预测与解释结果.csv`，包含极性、强度、三模态归因及解释评价指标。同名文件会被覆盖，可通过 `results` 更改目录。
