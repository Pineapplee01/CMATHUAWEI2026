下载目录为 `AAAcheckpoints`，包含模型权重和预训练模型。将其中的 `AAAmodel` 文件夹复制到项目根目录 `CPMCM`，与 `AAA提交版代码及结果`、`AAAdata` 并列。

## 共用运行环境

三个问题共用根目录的 `environment.yaml`，环境只需创建一次。所有命令在项目根目录 `CPMCM` 执行：

```bash
conda env create -f "AAA提交版代码及结果/environment.yaml"
conda activate CPMCM
```

环境为 Linux、Python 3.11.16、PyTorch 2.6.0+cu124、Transformers 4.46.3。后续运行时激活 `CPMCM` 环境即可。

## 默认权重设置

问题二和问题三共用 `AAAmodel/checkpoints/selected/problem2/` 下的正式权重：对齐版本为 `aligned_gate_B0_primary.pt`，未对齐版本为 `unaligned_gate_B0_primary.pt`。配置已指向这些文件，无需重命名或另行复制。

`aligned_init_boundary010.pt` 用于问题二对齐模型的训练初始化，不用于最终预测。

## 数据与运行

附件2直接使用以下目录内已处理的 NPZ 数据和 `scaler_params.npz`，无需重复预处理：

```text
AAAdata/Appendix_2/对齐版本/
AAAdata/Appendix_2/未对齐版本/
```

模型需使用对应数据版本中提供的标准化参数。
