# 问题二运行说明

所有命令在项目根目录 `CPMCM` 执行。运行前按 [共用环境与模型说明](../模型下载与使用说明.md) 配置环境和模型。

## 输入与配置

辅助功能位于本问 `代码/q2_utils.py`。附件2直接读取以下目录的 `train.npz`、`valid.npz`、`test.npz` 和 `scaler_params.npz`，无需重复预处理：

```text
AAAdata/Appendix_2/对齐版本/
AAAdata/Appendix_2/未对齐版本/
```

配置分别为 `代码/config_aligned.json`、`代码/config_unaligned.json`。`data_dir` 指定数据目录，`checkpoint` 指定权重，`output` 指定输出。对齐训练还需配置中 `init_checkpoint` 指定的初始化权重。

## 运行

```bash
# 训练完整模型
python "AAA提交版代码及结果/问题二/代码/aligned.py" train --device cuda:0
python "AAA提交版代码及结果/问题二/代码/unaligned.py" train --device cuda:0

# 验证集评估；测试集将 valid 改为 test
python "AAA提交版代码及结果/问题二/代码/aligned.py" evaluate --split valid --device cuda:0
python "AAA提交版代码及结果/问题二/代码/unaligned.py" evaluate --split valid --device cuda:0

# 附件3预测
python "AAA提交版代码及结果/问题二/代码/aligned.py" predict --device cuda:0
python "AAA提交版代码及结果/问题二/代码/unaligned.py" predict --device cuda:0
```

附件3的两版原始 PKL 分别放在 `AAAdata/Appendix_3/对齐版本`、`AAAdata/Appendix_3/未对齐版本`，每版30条。

`--device cpu` 使用 CPU；`--config 配置文件.json` 使用其他配置。重新训练会写入 `checkpoint`，独立实验需同时更改权重与输出路径。

## 输出

评估在终端输出完整输入及局部30%连续缺失下的 Accuracy、Macro F1、中性 F1、MAE。附件3预测写入 `主要结果/对齐版本_附件3_预测结果.csv` 和 `主要结果/未对齐版本_附件3_预测结果.csv`。同名结果会被覆盖。
