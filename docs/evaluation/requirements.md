## 团队评分协议（不是题面原文）

| ID | 选择与依据 | 验收方式 |

| TEAM-01 | 用户确认：固定反归一化后clip到[-3,3]，保留原始预测；不使用批次Min-Max | 单样本／批次相同输出、越界示例、反归一化测试 |

## 论文原生／基线专用设置

AUMDF的教师—学生训练、随机位置缺失训练、七级与非零二分类诊断、检查点选择目标均是基线或团队适配设置，不是官方硬要求。采用连续缺失训练是一种可选方案；官方要求是解决和验证连续局部缺失问题，未指定必须使用哪种训练增强。

验收范围：本轮完成统一预测评分能力及AUMDF接入，不代表三道题或整个竞赛提交已完成。尚未接入的参考算法不能自动视为符合本协议。
