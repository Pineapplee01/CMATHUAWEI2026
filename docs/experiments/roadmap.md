# 实验路线

1. **初始化门**：复制数据、通过契约测试和完整数据探针。
2. **问题1门**：完成100条原始视频特征、对齐规则、manifest和典型样本复核。
3. **问题2门**：按 [reference.md中的对比方法簇协议](../../references/reference.md#101-对比方法簇与统一实验协议) 先完成L0/L1/MulT，再完成P-RMF、CMAD、AUMDF或主模型；使用同一连续区间mask矩阵，完成缺失类型/位置/时长消融和附件3预测。
4. **问题3门**：至少比较Concat-MLP、EF-LSTM、Graph-MFN/DFG和主模型；完成模态贡献删除验证、证据定位、解释卡和附件4预测。
5. **论文门**：固定配置、记录指标、生成图表、检查匿名和50MB限制。

每一门都必须保存配置、随机种子、环境版本和输入特征版本。
