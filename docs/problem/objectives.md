# 三项任务目标

## 问题1：特征提取与时序对齐

输入为附件1的100条原始视频及标签。输出需要记录文本、语音、视觉特征、有效长度、位置映射、填充规则、工具版本和完整样本覆盖，并提供至少一个可回看的典型样本。

## 问题2：局部缺失鲁棒预测

使用附件2训练/验证数据构建极性分类和强度回归模型；训练阶段模拟局部连续缺失，验证缺失类型、位置和时长影响；最终对附件3输出全量预测文件。

## 问题3：可解释情感预测

使用附件2学习同时输出极性和强度的模型，并额外输出模态贡献、主要模态和局部证据定位；最终对附件4输出预测与解释文件，并用原始视频复核证据。

## 共同边界

Accuracy/F1 用于分类，MAE/Pearson 用于强度回归。模型、阈值和结构只能依据附件2训练/验证划分选择；附件3/4是无标签专项测试集。
