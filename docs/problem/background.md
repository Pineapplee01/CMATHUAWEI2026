# 题目背景知识

## 多模态情感预测

真实交互中的情感由文本语义、语音韵律、面部表情和肢体动作共同表达。文本、语音和视觉在采样频率、特征维度和时间尺度上不同，直接拼接会产生时间对应误差，因此需要明确的时序组织。

## 时序对齐

对齐是把不同模态的有效位置映射到共同时间组织；对齐版本将三种模态都组织为最多50个位置，非对齐版本保留文本50个位置以及语音/视觉最多500个独立位置。对齐版本是文件属性，时序对齐是处理步骤，二者在术语上分开。

## 局部模态缺失

题目中的缺失是模态内部连续时间区间的特征不可用或全零，不代表整个模态不存在。模型因此需要同时接收数值序列和缺失/有效掩码，并分析缺失模态、位置和时长的影响。

## 可解释性

可解释输出至少包含预测极性、预测强度、各模态贡献、主要参考模态和关键证据位置。证据必须能回映到文本片段、语音时间段或视频关键帧；贡献分数用于复核，不直接等同于因果关系。
