# ADR-003：将最终输出适配与统一评分分离

## Status

Accepted，2026-09-23。用户已接受统一输出规则。

## Context

项目共享MAE直接计算输入，AUMDF指标函数却先截断；常数Pearson分别返回0与None。两入口的不同隐含行为使跨模型结果不能直接比较。题面规定指标与标签语义，但没有提供所有评分细节。

## Decision

采用 [e-competition-v1](../evaluation/protocol.md)：模型独立适配器恢复量纲并固定截断，保留raw和final；纯评分器接收final强度及极性，严格校验但不更改值。共享CSV保持完整精度，按ID检查全量覆盖。所有基线接入同一评分包；AUMDF仅保留论文辅助诊断与兼容字段。

题面硬要求、团队约定与论文设置分别列入 [需求清单](../evaluation/requirements.md)。评分协议版本随报告保存。

## Alternatives

- 各模型保留独立评分：迁移少，但容易出现口径漂移，拒绝。
- 在共享评分器自动截断：调用简单，但掩盖提交值与得分值不一致，拒绝。
- 评分原始无界输出：可作诊断，不能充当用户已选定的有界最终输出协议。

## Consequences

收益：同一提交值对应同一成绩；不依赖具体深度学习框架；异常不被静默掩盖。

代价：旧调用者必须显式适配输出，Pearson调用者须处理None；参考实现独立运行时需能导入共享源码。不同分类头允许各自给出极性，但须遵守统一验证选择和最终值评分原则。

迁移不重写历史报告／检查点。旧结果重算只核对既有最终预测，不补造raw值。未来官方澄清需新增协议版本并标明重算影响。
