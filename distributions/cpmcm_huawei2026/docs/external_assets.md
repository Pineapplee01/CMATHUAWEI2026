# External Assets

The distribution excludes raw data, model weights, pretrained model directories,
and external feature extraction tools.

At runtime, set:

```bash
CPMCM_HUAWEI2026_ASSET_ROOT=/path/to/assets
```

The asset root should contain:

```text
AAAdata/
AAAmodel/
AAAcheckpoints/
```

Only README placeholders are included under `external_assets/`.
