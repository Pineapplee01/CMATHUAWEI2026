# 问题二对齐版：敏感结果分析报告

> **数据划分说明**：下文「完整输入」对照、组件拆除，以及表2–表6中对缺失跨度 / 模态 / 位置的**滑动扫描**，均在附件2 **测试集**（`test`，727 条）上冻结评价；验证集仅用于训练时选 epoch，不参与本报告滑动网格。缺失协议为 7 模态 × 6 跨度 ×（3 固定位置 + 3 次随机掩码）= **252** 组/seed。

## 等权汇总规则

1. 随机位置：同一（模态, 跨度, random）对 3 个掩码 seed 先算术平均；
2. 四位置等权：start / middle / end / random 再算术平均；
3. 七模态等权：T/A/V/TA/TV/AV/TAV 再算术平均；
4. 跨训练 seed：对三颗报告种子再算术平均。
