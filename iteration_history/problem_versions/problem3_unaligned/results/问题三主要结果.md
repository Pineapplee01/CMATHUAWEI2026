# 问题三主要结果（未对齐版·500→50池化）

## 1. 建模原理、网络结构、目标函数、训练方案与关键参数

采用已冻结的问题二 aligned_v4 预测器，在输入层进行模态删除、精确 Shapley 分解和局部窗口遮挡。注意力权重仅属于网络内部机制，本报告不把它直接当作决策贡献。解释不参与训练，也不宣称提升预测性能。

**输入与掩码**：文本为通用 bert-base-uncased 初始化、由当前检查点编码的逐槽 768 维隐藏态，音频 74 维、视觉 35 维，每模态保留原始 50 槽。有效范围 P 与观测状态 O 分开保存，模型使用 M=P∧O。原始全零向量表示该模态该槽缺失；音频缺失不会自动使视觉缺失。标准化数据不重复缩放；专项原始数据按训练集参数缩放一次。删除部分文本后，在 BERT 编码前遮挡词元并重新编码，避免已删除内容残留在上下文特征中。

**网络结构**：三模态各自 Linear→GELU→Dropout 投影至 96 维，叠加位置及模态嵌入；将 150 槽作为四头跨模态注意力的查询，可见槽作为键和值，全缺失时使用空键。残差、LayerNorm 和 96→192→96 前馈后，每模态分别做均值池化和可学习注意力池化。六个 96 维池化向量与三个观测比例拼成 579 维，融合至 192 维；分类 logits 为文本池化分类头加上可学习比例的融合分类头，回归头为 3·tanh。缺失槽上的跨模态信息是网络计算结果，不是该缺失模态提供的原始证据。

**训练目标**：L₀=加权CE₀.₀₃(c,p)+0.2·Huber(y,r)+0.1·meanₖ₌₀,₁[(Σⱼ≤ₖpⱼ−1[c≤k])²]；完整视图与缺失视图联合训练：L=L₀(full)+0.4·min(1,e/5)·L₀(partial)+λ(e)·L_boundary(full)。分类按训练集类别频数权重计算平滑CE后以样本权重和归一化；边界项对中性样本与|y|≤0.5的非中性样本作softplus(0.5−中性log-odds+弱极性log-odds)批内成对排序。λ(e)=boundary_weight·min(1,e/boundary_warmup_epochs)，参数为0时关闭。正式强度输出按预测类别投影：负类限制到[-3,-10⁻⁶]，中性为0，正类限制到[10⁻⁶,3]；同时保留原始回归值供核验。

**训练方案**：复用冻结检查点 `AAAmodel/checkpoints/runs/bert_balance025_seed2026/processed_po_seed2026.pt`；配置 `processed_po_seed2026`，训练数据 `/user_home/gaojianan/CPMCM/AAAdata/Appendix_2/标准化/对齐版本/processed_po`。AdamW，学习率 0.0001，weight decay=0.02，batch=16，最多 12 轮，patience=4，余弦学习率下限由是否微调BERT决定（微调为0，否则5×10⁻⁵），梯度裁剪1；以0.7×完整验证准确率+0.3×局部缺失验证准确率选模，保留第 2 轮。BERT微调=True，BERT学习率=1e-05，梯度累积=4，seed=2026。本任务不重新训练或使用附件4标签选参。

**身份核验**：checkpoint SHA256 `b5355d1a6903f174ee075edd79caa8d97426b31e6a29e7c9deddf27ffa109bfb`；scaler SHA256 `5101da0d28caed64ccc114dfc70dd2e11783aaaa0504237e1b1c9c13596459ac`。

**模态解释**：固定完整输入预测类别 c*，令 v(S)=p(c*|S)，枚举三模态全部8个子集。φₘ=Σₛ⊆M\{m}|S|!(2−|S|)!/3!·[v(S∪{m})−v(S)]。作用程度 dₘ=|φₘ|/Σⱼ|φⱼ|；主要参考模态取最大绝对贡献，正负号分别表示支持与抑制该类别；另外报告最大正贡献模态。相同公式单独分解最终投影强度，不能与概率贡献混用。零贡献时不指定主要模态。

**局部解释**：宽度 [1, 3, 5]、步长 2 的原槽连续窗口遮挡；分布为覆盖该槽窗口的“预测类概率下降/删除观测数”平均值，保留负值。该分布不满足可加贡献恒等式。用预算 30%、束宽 3、最多 3 段进行启发式保留片段搜索；仅当类别不变、概率差≤0.1、强度差≤0.3才标记 within_tolerance，否则明确标记不足。不是全局最小证据证明。

**时间回溯**：沿用问题一 v3 的 MFA 词级强制对齐，通过原始字符跨度将 BERT 子词桥接至完整词轴；保留全部词，特殊词元不伪造时间。音视频槽与词时间的关系仅为同槽参考，原始特征聚合规则仍未获证实。所有音视频定位都不得解读为已核实的特征时间或因果证据。
