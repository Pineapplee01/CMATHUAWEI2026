# 未对齐数据软注意力实验（seed2026）

原生文本50槽、音频500槽、视觉500槽，通用BERT全量微调，两个文本查询跨模态注意力模块，头数4、宽度96；边界λ=0.1、类别平衡β=0.25。训练10轮，valid选出epoch6，RTX4090训练约204秒，峰值分配显存约2.89GB（不含其他进程及缓存）。

| 指标 | 实测 |
|---|---:|
| 完整valid ACC | 64.97% |
| 完整test ACC | 69.60%（506/727） |
| 局部TAV30% test ACC | 63.14% |
| test Macro-F1 | 64.53% |
| 中性Precision | 48.06% |
| 中性Recall | 39.24% |
| 中性F1 | 43.21% |
| 强度MAE | 0.6361 |
| 强度Pearson | 0.6898 |

252组test场景均完成，每组727条，按真实有效长度独立抽取每种模态的连续区间，全部确认保留原有观测。完整指标见processed_po_seed2026/test_scenarios/local_scenarios.csv；注意力原始矩阵与图在该seed目录的figures下。注意力图为学习到的对应，不能直接解释为真实词级时间戳或因果重要性。

本轮未达到70%，比已有对齐模型72.63%低3.03个百分点，净少22条正确预测。不能因此单独判定未对齐数据或软注意力无效：本轮同时改变数据时间轴、融合结构和初始化来源，且仅有一个seed。结果独立保存，不替换已有正式模型，也不凭单次结果宣称增益。

新模型从通用BERT及随机融合层开始；没有继承历史对齐融合投影初始化。仅train参与梯度，epoch仅由valid选择，test场景不反过来挑epoch。实验参数、权重SHA、逐样本预测与实际缺失掩码均已保存。52项代码检查通过，关键测试覆盖第500槽梯度、掩码隔离与重载。
