# F3结构学习与独立消融（seed2026）

正式模型、权重和默认配置未修改。四组候选均使用全量BERT微调、边界最大λ=0.1、类别平衡β=0.25；不增加重建损失，保留0.2 Huber、0.1有序损失及原缺失监督渐增策略。

## 对照设计

F0：共同补全与固定窗口池化＋加性头；F1：F0改Concat-MLP；F2：F0在池化前加跨模态注意力；F3：两项同时启用。四组使用d=96、两层补全、4注意力头、5槽窗口，BERT学习率1e-5、其余1e-4、微批16累积4、最多12轮、patience4。epoch按0.7完整valid ACC+0.3局部30% valid ACC选择，之后计算test。

当前正式模型没有这套独立补全/可靠性/固定窗口结构，因此它是外部参照，不能把F3与正式模型的差异仅归因于新增MHA。F0—F3内部才是相同补全与池化条件下的两因素消融。与历史problem2_v4的冻结BERT实验不是同一批结果；历史64.42%属于valid ACC。

## 结构收益拆分（test ACC百分点）

只换头 F1−F0：+2.06；加性头上加交互 F2−F0：-2.34；Concat头上加交互 F3−F1：-3.16；完整F3−F0：-1.10。

本轮候选中test ACC最高为F1，72.63%（528/727）。F3相对正式模型变化+0.55个百分点。正式方案保持不动，所有候选独立保存。

只有一个seed，局部增益不等于跨seed稳定提升；测试集已多轮用于开发比较，不能当作未使用过的独立外部评估。候选与正式模型的初始化可迁移范围也不同：F3族只复制原投影/位置参数，新补全与头从随机初始化学习；不能据单次失败认定架构没有潜力。

## 实现与核验

全部F3模块位于problem2/model_f3.py，原正式模型仍走model.py的cross_attention分支。观测槽在补全阶段保持投影embedding，缺失槽由观测条件均值和任务门控生成；融合阶段每模态只读取其他两模态，α初值0.1。固定窗口池化附加观测/缺失/门控标记，Concat头直接产生3分类和1回归，回归经3tanh限制范围。详见[架构对照与推导](../../F3方案对照说明.md)。

已验证跨模态K/V排除本模态、padding隔离、缺失文本及缓存XT不泄漏、观测槽保留、BERT/补全/融合任务梯度、空输入稳定与权重重载。正式检查点SHA和正式训练配置在实验后再次核对保持不变。真实GPU名称、显存和时长、α、参数量、初始化加载键和模型SHA见comparison.csv/json。

## 本轮判断与复现

本轮最有价值的是F1：在共同补全与窗口池化基础上，Concat-MLP比加性头多判对15条，且少30,456个参数；没有靠增加参数量获得这部分提升。新增融合MHA在加性头和Concat头上都下降，暂不建议把这一层直接叠加到正式模型。

F1相对正式模型净多27条正确（修复56条、引入29条），test ACC提高3.71个百分点、强度MAE下降；局部缺失ACC则少1条正确（66.44%对66.57%）。这不是所有任务指标全面上升。F1的补全模块内部仍有观测条件注意力，所谓“不加交互”仅指不再新增池化前的第二个跨模态融合块。

正式模型历史batch顺序与本轮独立采样器不同，因此正式模型只是完整方案参照；F0—F3共同初始化和同序样本对照才用于区分两项模块。50项单元/集成测试通过，四组最终指标及检查点SHA复核见verification.json。
