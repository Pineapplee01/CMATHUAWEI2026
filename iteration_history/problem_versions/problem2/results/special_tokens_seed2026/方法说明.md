# F1的CLS/SEP全局输出分支

本轮比较原正式F1、F1+CLS、F1+CLS+SEP。不是给BERT再次插入标记：数据已有CLS/SEP且已参与编码；改动是把它们最后一层的输出接到最终任务头。

设当前观测视图的BERT输出为H，特殊词元集合S为{CLS}或{CLS,SEP}。每个特殊词元独立取出其槽位输出，经过共享投影：

\[
g_s=\operatorname{GELU}(\operatorname{LN}(W_g H_s+b_g))\in\mathbb R^{96}.
\]

文本局部缺失时，先屏蔽被删除词元，再计算整个BERT输出H，不能从完整视图缓存取CLS。特殊词元不存在时该分支对应向量置零（包括投影偏置），不移动音视频槽位。

令原F1三模态池化拼接为z，则新头为

\[
h=\operatorname{GELU}\left(W_z z+W_s[g_s]_{s\in S}+b\right),\quad
u=W_o\operatorname{Dropout}(h)+b_o.
\]

该式等价于直接拼接后做一层Linear；采用分块参数形式，是为了保留原F1头的初始化，避免同时改变既有分支。输出仍为3个分类logits与1个强度原始分数，损失不变。两个新增方案都使用相同的共享投影初始化，CLS+SEP的首层输入维度更大，因此该层随机初始化不同；不声称全部随机扰动逐步相同。

两组均保留seed2026、processed_po、float32、全量BERT微调、边界λ=0.1、β=0.25、BERT学习率1e-5/其余1e-4、微批16累积4、最多12轮、patience4，以及相同初始化来源与缺失协议。epoch按valid完整/局部ACC的70/30组合选择，选好后计算test，不根据逐轮test选epoch。

原F1使用已完成的同seed实验作为基线，没有重新训练。新模块在所有原模块构造后初始化，测试检查共享参数初始化一致；训练开始前重置随机状态、逐epoch固定采样顺序。正式权重与默认配置保持原F1，实验结果单独保存。

复现（需使用新的run-name）：

```bash
python run_problem2.py --config problem2/results/special_tokens_seed2026/cls_config.json --seed 2026 --run-name my_f1_cls --device cuda:3
python run_problem2.py --config problem2/results/special_tokens_seed2026/cls_sep_config.json --seed 2026 --run-name my_f1_cls_sep --device cuda:3
```

新增两项代码检查专门验证特殊词元分支的梯度、缺失隔离、重载、初始化与缺少标记时的行为。全套52项代码检查通过；本轮新增模型训练只有两组。
