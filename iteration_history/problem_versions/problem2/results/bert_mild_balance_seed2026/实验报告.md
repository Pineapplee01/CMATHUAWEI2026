# BERT微调＋边界训练＋更温和类别平衡

本轮仅改变β，使用同一通用BERT初始化、同一本题融合层初始化、seed2026、processed_po、float32和训练预算。新训练两组，β=0复用上一轮同条件结果。完整BERT学习率1e-5、融合层1e-4、边界最大λ=0.1、前三轮渐增，微批16、累积4次，最多12轮、patience4；按0.7完整valid ACC+0.3局部30% valid ACC选epoch，之后评估test。

类别权重只由train的负967、中758、正1670计算：w_c正比于[N/(3n_c)]^β，再归一化到训练样本加权均值1。额外中性倍率保持1。

## 结论

两个三项组合中，β=0.25的test ACC较高，为68.91%（501/727），相对β=0净变化+0条正确。
β=0与β=0.25的test ACC并列最高，均为68.91%；超过70%需509条正确，尚差8条。

每组实际seed、权重、检查点SHA、GPU名称和耗时见comparison.csv。selected_config.json引用本轮最佳三项组合，保留原候选以便对照。仅比较一个seed，不声称收益稳定；test已多轮用于开发比较，结果不是独立留出评估。

沿用既有模型、边界损失和类别权重实现，没有增加新网络模块，也没有修改原始标签、重采样或在test上搜索阈值。逐槽编码、局部缺失前遮蔽、仅新BERT隐藏态应用一次train scaler的规则均保持不变。

## 采用的配置与运行

按用户指定的三项组合，采用β=0.25：整体测试准确率与β=0持平，中性正确由45/158提高到51/158，中性召回28.48%→32.28%、F1 36.29%→39.08%。相对β=0修复8条原错误，同时引入8条新错误，不能宣称总体准确率提升。局部30%缺失ACC从66.85%降至66.57%，需要保留该取舍。

根目录总训练脚本默认配置已改为 `configs/problem2_bert_finetune.json`，其中β=0.25、边界λ=0.1、全量BERT微调。轮数、batch、学习率和数据版本遵循CLI优先、否则继承配置，避免旧的冻结模型默认参数覆盖微调设置。现在可直接运行：

```bash
python run_problem2.py --seed 2026 --run-name my_bert_boundary_mild
```

默认seed列表仍是2026—2030，可自由指定；本轮只实测2026，未运行其余seed。新配置引用β=0.25候选检查点，旧正式检查点与不加权微调候选都保留。40项单元/集成测试通过，包括训练预算继承及CLI覆盖检查。

所采用β=0.25候选已完成附件3的30条在线推理，结果见[附件3预测](appendix3/附件3_预测结果.csv)；附件3没有真值标签，不计算准确率。
