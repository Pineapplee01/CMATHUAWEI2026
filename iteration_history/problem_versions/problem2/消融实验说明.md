# 六组连续缺失消融实验：代码、公式与运行说明

## 正式模型与研究实验的边界

问题二正式模型的权重固定在 `AAAmodel/checkpoints/problem2_aligned.pt`，原test ACC为72.63%。全部架构集中在 `problem2/model.py`。保留已有检查点的 `architecture=f3` 读入兼容，新配置明确写 `architecture=problem2`。旧联合注意力、额外F3融合、加性头和CLS/SEP分支已退出主代码，归档在 `archives/20260925_problem2_f1_cleanup`。

本矩阵研究门控G、一致性C、重构R；问题二正式模型原有的补全可靠性门控不能在没有补全时独立验证，且原正式模型没有显式一致性/重构损失。因此另设 `architecture=ablation` 研究族，共用问题二正式模型的逐槽BERT、投影、窗口池化与Concat头，但显式开关研究模块。研究完整模型F不等于问题二正式模型，不能将这组实验冒称为“已采用正式模型的逐项拆除消融”，也不自动替换正式权重。

## 六组定义与唯一变量

| 显示组 | 训练检查点 | 评估输入 | 动态门控 | 一致性 | 隐空间补偿及重构监督 |
|---|---|---|---|---|---|
| B0完整基线 | Bm | 原始完整视图 | 关 | 关 | 关 |
| Bm缺失基线 | Bm | 连续局部缺失 | 关 | 关 | 关 |
| G门控模型 | G | 同一缺失视图 | 开 | 关 | 关 |
| C一致性模型 | C | 同一缺失视图 | 关 | 开 | 关 |
| R重构模型 | R | 同一缺失视图 | 关 | 关 | 开 |
| F完整研究模型 | F | 同一缺失视图 | 开 | 开 | 开 |

B0与Bm必须共用检查点，才能将差异归因于评估时输入被遮挡。所有训练组均采用相同完整/缺失视图监督，不另给B0不同训练条件；B0是完整输入参考而非严格性能上限。“完整”指无额外人工遮挡，已有天然缺失仍保留。六个显示组对应每seed五次训练，五seed共25次训练，不能称为30个独立模型。

G/C/R相对Bm分别增加一个模块；R的“补偿模块”包含补偿网络与对应监督，当前矩阵不能进一步分离网络容量和重构损失的收益。F同时启用三项，可衡量整体组合收益，但没有GC/GR/CR组，不足以严格估计交互协同。

## 模型公式

先按观测掩码M=P∧O构造逐槽表示。文本缺失发生在BERT编码之前；无CLS广播，不使用外部情感预训练模型，不重复缩放音视频数据。基线为

\[
H^{base}_{m,t}=M_{m,t}E_{m,t},\qquad
z=[\operatorname{WindowPool}(H_T);\operatorname{WindowPool}(H_A);\operatorname{WindowPool}(H_V)],
\]

其中池化特征仍附加观测、缺失、可靠性三个通道，与问题二正式模型的接口维度一致。无重构时可靠性为M，有重构时为P，动态门控是另一个明确模块，不偷用问题二正式模型的方差门控。

**G：逐槽动态模态门控。** 同一对齐槽的三模态观测表示、M与P共同输入两层MLP，生成三个分数：

\[
a_t=\operatorname{MLP}([M_TE_T;M_AE_A;M_VE_V;M_t;P_t]),\quad
w_{m,t}=K_t\frac{P_{m,t}\exp(a_{m,t})}{\sum_jP_{j,t}\exp(a_{j,t})},\quad K_t=\sum_jP_{j,t}.
\]

分母为空时输出零。有效模态权重的均值为1，基线是有效模态权重均为1；不是把权重直接当解释贡献率。G作用于已有观测，F同时作用于观测和补偿表示。

**R：隐空间补偿。** 复用正式模型的两层观测条件注意力补全网络，得到投影到d=96后的估计Z，仅填入P=1、M=0的位置：

\[
\widetilde H=M\odot E+(P\land\neg M)\odot Z,\qquad H=w\odot\widetilde H.
\]

完整视图通过当前模型eval前向得到停止梯度的目标E*，只在人工遮掉、原本真实可观测的位置集合D计算监督：

\[
s_i=\max(0.1,\sqrt{\operatorname{mean}_j[(E^*_{ij})^2]}),\quad
\mathcal L_R=\operatorname{SmoothL1}_{i\in D,j}(Z_{ij}/s_i,E^*_{ij}/s_i).
\]

这里根号内是各分量平方的均值；目标和尺度均停止梯度。不存在真实目标的天然缺失和padding不进入重构损失。完整隐态只进入训练目标，不作为缺失分支输入。R/F推理不需要完整视图。

**C：完整—缺失一致性。** 完整视图作为停止梯度的在线教师，使用当前权重、eval模式，不是另一个外部情感教师：

\[
\mathcal L_C=D_{KL}(\operatorname{sg}(p_{full})\Vert p_{miss})
+0.2\operatorname{SmoothL1}(\hat y_{miss},\operatorname{sg}(\hat y_{full})).
\]

分类一致性和强度一致性都作用于缺失视图。强度使用原始回归值，避免提交投影导致人为一致。

总目标保留已有完整/缺失任务监督、平滑类别加权CE、强度Huber、有序项和中性边界：

\[
\mathcal L=\mathcal L_{task}+\lambda_C\mathcal L_C+\lambda_R\mathcal L_R.
\]

研究配置默认λC=λR=0.1，关闭模块对应系数严格为零。这是预先指定的实验起点，不宣称已优化；需要调参时只能在训练/验证划分完成，不能根据最终test反复调整系数。

## 连续缺失协议与数据划分

训练采用7种模态组合×3种缺失跨度（10%、30%、50%）的固定随机连续区间。联合缺失模态共享同一槽位区间；根据有效槽轴选区间，若会删空任何原非空模态则对共同区间缩短，保证至少保留一个观测。每条记录保存起止槽、实际删掉的观测数与比例。标称跨度与实际删去的观测比例不能混用。

训练只使用train。epoch统一按0.7×完整valid ACC+0.3×TAV30 valid ACC选择。检查点冻结后才计算test场景，场景指标不反过来选epoch。五seed默认2026–2030；掩码seed独立设为5026–5028，对各模型完全相同。

主指标：随机位置30%缺失，在每种模态组合内平均三个掩码，再等权平均7种组合。热力图额外分析开头、中部、结尾；跨度曲线分析单模态10%至50%，0%使用各模型自身完整输入结果。误差区间是跨训练seed标准差，不是把重复掩码当独立训练；单seed不估计标准差。

所有seed共用历史本题投影初始化与通用BERT起点，故这是“给定共同初始化的后续训练随机性”比较，不是五套独立的预训练历史。原test已用于项目开发，论文不能将其称为全新盲测。

## 代码职责与运行

- `model.py`：唯一架构文件，正式模型、消融开关、损失。
- `training.py`：共同训练、valid选epoch及.pt保存重载。
- `local_missingness.py`：原正式模型协议与新联合连续缺失协议，互不混用。
- `ablation.py`：五seed实验编排、数据/代码身份核验、断点续跑。
- `ablation_analysis.py`：冻结后场景评估、稳定性、重构和门控干预。
- `ablation_plots.py`：六张图，自动导出300dpi PNG及矢量PDF，同时输出图注与论证目标。

在项目根目录、CPMCM环境中执行：

```bash
# 先进行小样本一轮GPU端到端检查，产物带SMOKE水印，不作为论文结果
python -m problem2.ablation --smoke --run-name continuous_ablation_check

# 完整默认实验：5个seed，25次训练，6个实验组
python -m problem2.ablation

# 自定seed及实验名
python -m problem2.ablation --seeds 2026 --run-name continuous_one_seed

# 断点继续：配置/代码/数据必须与原协议一致
python -m problem2.ablation --resume

# 只从已有结果重新绘图
python -m problem2.ablation --plots-only
```

默认配置为 `configs/problem2_ablation.json`。不同实验使用不同run-name，既有目录禁止静默覆盖。恢复只跳过身份匹配的已完成训练/分析项；被中断的未完成训练会从头重跑，而非从优化器中间状态继续。

实验结果：`problem2/results/ablations/<run_name>/`，含逐seed指标、逐样本预测、真实缺失区间、机制诊断、六张图和Markdown说明。权重：`AAAmodel/checkpoints/ablations/<run_name>/`。小样本检查保存 `smoke_test=true`，目录带_smoke，绝不替换问题二正式模型。

## 六张图与推断限制

主图为模块消融、缺失跨度曲线、模态×位置热力图；辅助图为完整/缺失稳定性、隐空间补偿、门控响应及干预。运行后 `图表说明.md` 自动列出每张图的名称、类型、内容、图注和科学论证目标。任何图都不预写“模块一定有效”的结论。

门控固定值仅从train输入估计，样本间打乱只用于同检查点推理诊断；原始权重不修改。重构参考使用同一模型同一层，观测均值对照仅用缺失输入重新编码的特征，避免完整文本上下文泄漏。热力图样本按重构误差中位数选择；目标/重构范数同时记录，防止把表示坍塌误当重构成功。
