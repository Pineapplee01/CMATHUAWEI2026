# 问题一运行说明

所有命令在项目根目录 `CPMCM` 执行。运行前按 [共用环境与模型说明](../模型下载与使用说明.md) 配置环境和模型。

另需安装 MATLAB、MFA、FFmpeg、OpenFace 和 COVAREP。重新提取语音特征还需 `covarep_batch.m`、`wavread.m`，可放入本问的 `代码` 目录；这两个辅助文件不在当前附件中。

## 输入与配置

输入为 `AAAdata/Appendix_1/label-100.xlsx` 及同目录下的 `MOSEI数据集部分原始视频-100条`；`media_qc/results_full.csv` 存在时读取质量记录。

方法 A 按词元组织特征，方法 B 按词组织特征。配置分别为 `代码/config_a.json`、`代码/config_b.json`，其中 `paths` 指定数据、模型、工具和输出路径。

## 运行

```bash
python "AAA提交版代码及结果/问题一/代码/method_a.py" extract --config "AAA提交版代码及结果/问题一/代码/config_a.json"
python "AAA提交版代码及结果/问题一/代码/method_b.py" extract --config "AAA提交版代码及结果/问题一/代码/config_b.json"
```

默认处理100条样本。`--limit 1` 只处理首条，输出目录增加 `_smoke_1` 后缀；`--keep-tmp` 保留中间文件。

## 输出

结果分别写入 `主要结果/方法A`、`主要结果/方法B`，包含三模态特征及掩码 NPZ 文件。字段与读取方式见 [特征文件说明](主要结果/特征文件说明.md)。同名文件会被覆盖，可通过 `paths.output` 更改目录。
