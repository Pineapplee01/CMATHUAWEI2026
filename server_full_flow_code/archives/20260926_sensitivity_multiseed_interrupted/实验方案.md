# 当前架构超参数敏感性实验方案

实验执行前固定如下设计。训练集拟合，验证集选轮次和参数，不读test或附件3、4。

| 参数 | 默认值 | 候选值 | 检验问题 |
|---|---:|---|---|
| 类别平衡β | 0.25 | 0、0.125、0.25、0.5 | 少数类纠偏与误吸收正负样本如何权衡 |
| 边界权重λ_max | 0.1 | 0、0.05、0.1、0.2 | 无约束、半强度、默认、双强度的区别 |
| BERT学习率 | 1e-5 | 5e-6、1e-5、2e-5 | 适应速度与过度更新的折中 |
| 未对齐窗口半宽上限 | 0.2 | 0.1、0.2、0.3 | 局部时间先验与上下文覆盖的折中 |
| 未对齐时间惩罚 | 2 | 1、2、4 | 内容匹配与时间距离约束的折中 |

对齐seed固定2027、2028、2035；未对齐seed固定2026、2031、2033。每个取值均运行全部对应seed。每次最多12轮，patience=4，float32，全量BERT微调，其他配置不变。

单因素阶段：对齐9套配置×3seed，未对齐13套配置×3seed，共66次。默认配置重新训练。然后每种布局各增加一套由单因素候选最优值组成的联合配置×3seed，共6次复核，预计总计72次训练。

选择规则：每次运行先选择S=0.7×完整验证Accuracy+0.3×TAV局部30%缺失验证Accuracy最高的轮次；候选配置再按三个seed的S均值比较。完全同分时依次按完整Macro-F1均值、较小的S标准差、是否默认配置决胜。全部Accuracy、Macro-F1、MAE、Pearson及中性Precision/Recall/F1同时报告，不用临时改变选模规则来维护默认参数。

随机缺失掩码及样本顺序在对应seed之间配对。图上误差棒使用样本标准差；不是置信区间。训练预算与早停规则一致，训练轮数不强制相等。记录实际λ_e（前三轮预热）、最佳轮次、参数文件身份和每次GPU训练耗时。

只能据此给出当前范围内的参数依据，不能声称全局最优。若原默认值不占优，报告明确写出；单因素最佳组合必须重新训练检验，不能将不同单因素实验的增益直接相加。
