| 文件 | 身份 |

## 结果摘要（详见 problem2/级联试验记录.md）

- 级联：主模型 log_neu CV-AUC 0.7630 已是全部证据最强，叠加先验/TF-IDF/时序统计仅 0.7762；决策级联在诚实CV下不超过基线，未读test。
- 软标签重训三变体（δ=0.5先验乘制 / δ=0.5 / δ=0.33）：best valid 0.6387 / 0.6250 / 0.6511，全部低于基线 0.6827。中性召回确实翻倍（0.27→0.53-0.58）但极性侧损失更大；软标签模型中性logit AUC（0.68-0.70）反而低于主模型（0.71），与主模型集成无增益。
- 结论：两条路径均为负结果，正式模型保持 main.pt（test 70.7015%）。

## 复现

在隔离目录解压 source_snapshot.zip，按 problem2/级联试验记录.md 的口径执行；权重 soft_label*.pt 在 AAAmodel/checkpoints/archive/soft_label_trial/，证据落盘在 problem2/results/cascade/。
