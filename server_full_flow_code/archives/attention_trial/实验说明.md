# 词元表示与注意力融合对照试验

基线：完整valid三分类Accuracy=497/728=68.2692%；主权重main.pt保持不变。仅当新方案独立重载后准确率严格提高才考虑替换，否则将试验源码和配置归档，正式代码恢复原最佳实现。

## 改动与公式

1. **词元级表示**：先删除不可观测BERT词元，再由保留WordPiece构造文本及字符区间。RoBERTa返回词元字符offset，按字符交叠长度映射回原50槽：

$$x_i=\frac{\sum_j |I_i\cap J_j|h_j}{\sum_j |I_i\cap J_j|}.$$

不读取完整raw_text恢复被遮挡内容。每槽取归一化后的前765维局部表示，最后3维仍放句级分类先验，保持原4维预测账本接口。标点/子词的拼接规则与跨度同时生成；不是拿CLS广播充当词级表示。全空输入返回零观测表示。

2. **质量感知窗口注意力**：每模态小型打分网络 $s_{mt}=v_m^T\tanh(W_mh_{mt}+b_m)$，对窗口内有效槽按 $a_{mt}\propto P_{mt}q_{mt}\exp(s_{mt})$ 归一化，输出 $u_{mw}=\sum_ta_{mt}h_{mt}$。全空窗输出0，状态标记仍按P平均，避免混淆有效范围和学习权重。三个打分网络末层初始为0。

3. **门控跨模态融合直接进入分类**：使用观测内容、位置、模态共同构造查询，交叉注意力仍只读取真实保留观测。观测槽表示为

$$h^{obs}_{mt}=(1-g_m)e_{mt}+g_m\operatorname{LN}(Q_{mt}),\quad g_m=\operatorname{sigmoid}(a_m).$$

$a_m$初始为-2，减小初始融合扰动。缺失槽沿用原均值/方差补全及可靠性门控。分类路径含此融合结果，因此完整观测下也能更新注意力权重。

## 对照与检查

模型仍为64维、2层4头，固定5槽窗口；无骨干扩宽/加深，无新增大型编码器。使用相同train/valid划分、种子和原主模型任务权重。新表示改变背景坐标，因此从预训练骨干重新训练，并只在train重估背景；最多30epoch、patience8。test不参与本次选择。

新增检查覆盖WordPiece跨度映射、特殊词元无时间支持、填充隔离、全空窗有限性、完整观测分类梯度到注意力层、账本重建。总计31项测试通过。训练命令明确CUDA_VISIBLE_DEVICES=3、device=cuda；实际训练PID及GPU显存记录见logs/attention_trial_gpu.log。

结果以训练历史和独立重载验证为准，不能把结构检查通过等同于准确率提升。若失败，baseline目录用于恢复正式源码，不保留本试验的条件分支和转发层。
