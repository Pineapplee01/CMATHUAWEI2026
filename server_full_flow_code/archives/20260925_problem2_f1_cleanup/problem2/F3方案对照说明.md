**采用更新（2026-09-25）：四组对照完成后，用户已指定采用F1。当前默认配置与正式权重均为F1；下文“当前正式模型”“不覆盖”描述的是实验开始时的旧方案与隔离策略。最新架构见[问题二建模思路](问题二建模思路说明.md)。**

本文依据用户提供的完整流程及工作区 `problem2_v4` 的现有实现核对，不代表F3已接入正式模型或取得新的test成绩。正式模型仍为全量BERT微调＋边界λ=0.1＋类别平衡β=0.25。

## 已找到的对应实现

| 阶段 | F3实现 | 当前正式模型的差别 |
|---|---|---|
| 单模态投影 | `problem2_v4/model.py` | 二者都有独立T/A/V投影 |
| 条件补全 | `problem2_v4/model.py` 与 `problem2_v3/completion.py` | F3独立推断均值和logvar；当前联合注意力同时承担缺失查询更新与交互 |
| 补全可靠性 | 由logvar和tau计算门控，仅缺失槽使用 | 当前输入融合头的是观测比例，没有同样的逐槽可靠性门控 |
| 池化前交互 | `problem2_v4/fusion.py` | F3每个模态只读取另外两个模态；当前150槽联合注意力允许同模态读取 |
| 池化 | `problem2_v4/heads.py::window_pool` | F3固定5槽窗口；当前为均值＋可学习注意力池化 |
| 融合头 | `ConcatMLPHead` | F3直接输出4维；当前有文本池化分类分支、融合修正分类分支及独立回归头 |

## F3的准确数据流

1. 原始模态特征经过独立投影，得到观测embedding。
2. 补全查询只读取保留下来的真实观测，预测每模态的均值与logvar。补全阶段观测槽保持投影后的观测embedding，缺失槽使用补全值和可靠性门控；padding槽不参与。所谓保留观测不是把768/74/35维原始输入直接送入同维融合。
3. 对每个模态m，Q来自自身，K/V来自另外两个模态的已补全序列：

\[
\widehat H_m=\operatorname{LN}\bigl(H_m+operatorname{Dropout}[\alpha_m\operatorname{MHA}_m(H_m,H_{-m},H_{-m})]\bigr).
\]

参考实现使用三套MHA参数，α有三个可训练标量，初值0.1；不是共享一套150槽自注意力。α未约束为正数。小初值减小交互分支初始幅度，但由于还有LayerNorm，不等于整个模块严格初始化为恒等映射。

4. 跨模态交互后附加观测、缺失、可靠性三个标记，以P为掩码做窗口均值池化。参考window=5，长度50得到10个窗口；再对每模态的非空窗口等权平均，得到维数d+3的z_m。它没有把10个窗口直接全部展开到MLP，也不是按每个窗口的有效槽数二次加权。
5. 拼接三模态向量，Linear→GELU→Dropout→Linear产生4维s，前三维为分类logits，第四维通过3tanh映射为强度。采用当前提交规则时，后续仍按预测类别投影强度，并另存原始回归值。

## 掩码与可靠性的含义

补全阶段K/V必须使用观测掩码M=P∧O；融合阶段使用有效范围P，因此可以读取另外模态的补全槽。不能将两种掩码混用，也不能在文本隐藏态已含完整上下文后才删除原词。

参考融合模块带可学习null key，保证另外两个模态均无有效槽时注意力仍有限。其null始终可读；它与当前补全模块仅在完全无观测时启用null的规则不同。padding查询的输出最终清零。

参考rec=0只关闭重建NLL，补全均值和门控仍通过分类/回归任务收到梯度。没有重建监督和校准检验时，可靠性q应描述为由预测方差参数化的任务门控，不应直接解释为校准置信度。

## 训练口径需要独立确定

用户参考F3使用冻结BERT，miss=0.1、rec=0、reg=0.05。当前正式方案则全量微调BERT、边界最大λ=0.1、β=0.25、Huber权重0.2、有序权重0.1及渐增缺失监督。`miss=0.1` 是缺失视图任务损失权重，并不是人为缺失比例。

有两种不同实验：保留正式训练目标仅迁移F3结构，或者复现参考的冻结编码器与损失配置。它们不能混为同一次“仅改融合头”的消融。当前正式隐藏维数96，而参考F3配置为64、补全层数2；复用模块时也应记录这些差别。参考配置另有standardized_clip=5，不能顺便迁入当前禁止重复预处理/裁剪的主链路。

已核实 `problem2_v4/results/fusion/fusion_summary.csv` 的62.77%、63.87%、64.42%分别属于F0、F1、F3的valid_full_acc，不是test ACC，不能直接与正式模型68.91%的test比较。

用户已确认保留正式方案和权重不动，只研究F3结构。已在 `problem2/model_f3.py` 独立实现候选，并通过统一训练/重载接口接入；不改正式架构分支。四组实验已完成，结果见下方报告。


## 本轮实际迁移与四组消融

四组使用共同的两层观测条件补全、可学习门控、5槽固定窗口池化；d=96、4注意力头，参考层内dropout=0.1、投影dropout=0.2。BERT微调、边界训练与类别加权全部保留当前正式配置，不使用参考的冻结BERT或miss/reg损失系数，也不引入裁剪和重建损失。

| 本轮组名 | 池化前跨模态融合 | 池化后头 |
|---|---|---|
| F0 | 无 | 单模态＋两两交互加性头，非空窗口归一化 |
| F1 | 无 | Concat-MLP，输出3分类＋1回归 |
| F2 | 有，三套MHA，α初值0.1 | 加性头 |
| F3 | 有，三套MHA，α初值0.1 | Concat-MLP |

这四组与历史problem2_v4同名实验不是同一批成绩。F1−F0衡量头替换，F2−F0衡量前置跨模态融合，F3−F1衡量Concat头上增加跨模态交互；比较F3与当前正式模型则是整个表示/池化/融合方案的比较，不能归因于单独某一层。

初始化共用本地通用BERT和同一个本题投影层检查点，仅迁移project、position、modality；新的补全和头不从不兼容的正式头中静默加载。四组共同部分初始化一致，同类头在注意力开关两侧初始化一致，逐epoch用相同seed的独立采样器固定训练样本顺序。结构不同导致dropout随机数消耗不同，不能声称全部随机扰动一致。全部使用seed2026、微批16累积4、最多12轮和patience4，学习率及损失不变。正式模型历史训练使用全局随机状态生成batch顺序，本轮F3族改为独立的逐epoch采样器，因此正式模型对照并非连batch随机序列都匹配的严格单因素实验。

模型工厂以architecture=f3识别候选，既有cross_attention正式模型仍走原分支。参数、掩码、训练/验证划分和初始化来源均写入独立实验协议；正式配置及权重不覆盖。若结果不优于正式方案，不将F3自动设为默认。
