# 问题二统一运行脚本

项目根目录入口：`run_problem2.py`。使用CPMCM环境，默认读取 `configs/problem2_bert_finetune.json`：F1（architecture=f3、f3_cross=false、f3_head=concat）、float32、processed_po、全量BERT微调＋边界λ=0.1＋更温和类别平衡β=0.25。训练预算为12轮、patience4、微批16累积4，BERT学习率1e-5、融合层1e-4。命令行优先于配置，未指定参数时继承配置。

## 指定你想尝试的seed

```bash
conda activate CPMCM
# 一个seed，完整训练后输出验证/test结果
python run_problem2.py --seed 42 --device cuda:3

# 自由指定任意数量的seed
python run_problem2.py --seeds 7 42 123 888 2026 --device cuda:3

# 自定义实验名称，便于之后查找
python run_problem2.py --seeds 11 22 33 --run-name my_seeds --device cuda:3

# 比较两套标准化输入，每套都运行指定seeds
python run_problem2.py --config configs/problem2_aligned.json --seeds 42 123 --datasets processed processed_po --device cuda:3

# 自定义训练轮数、早停、batch与学习率
python run_problem2.py --seed 42 --epochs 12 --patience 4 --batch-size 16 --lr 0.0001
```

不传seed时，默认运行2026、2027、2028、2029、2030；`--seed`和`--seeds`作用相同。seed必须为0～4294967295范围内不重复的整数。GPU编号按实际环境修改，例如`--device cuda:0`。

训练seed控制初始化、batch顺序、dropout等随机过程；局部缺失掩码继续固定原协议，便于比较seed造成的波动。当前微调配置让所有seed从同一通用BERT及同一本题融合检查点开始；该融合初始化来自之前seed2026的训练，各seed分别改变后续训练的随机过程。它不是多个从零训练的独立全流程实验，也不复用已完成seed的最终结果。

## 类别不平衡：按训练集频数计算权重

当前默认 `balance_beta=0.25`、`neutral_weight=1.0`；β=0.1和0.25的单seed对照已完成，见文末组合报告。由完整训练集标签统计负、中、正三类数量，按逆频数的β次幂计算初始权重；不读取验证集或测试集类别比例，也不按每个batch重新估计类别频数。

当前训练类数 `[967,758,1670]` 在β=0.25时对应权重约 `[1.0513,1.1173,0.9171]`。完全逆频数β=1时才是 `[1.1703,1.4930,0.6776]`，使三类累计样本权重相等，不保证实际误差或梯度相等，也不保证总体ACC必然上升。

```bash
# 完全逆频数平衡对照（非当前默认），每个seed独立继续微调
python run_problem2.py --seeds 2026 2027 2028 2029 2030 --balance-beta 1 --neutral-weight 1 --run-name balanced_b1 --device cuda:3

# 温和平衡对照
python run_problem2.py --seeds 2026 2027 2028 2029 2030 --balance-beta 0.5 --neutral-weight 1 --run-name balanced_b05 --device cuda:3

# 原始未加权对照
python run_problem2.py --seeds 2026 2027 2028 2029 2030 --balance-beta 0 --neutral-weight 1 --run-name balanced_b0 --device cuda:3
```

`--balance-beta` 取0到1之间的有限数；0关闭频数平衡，1为逆频数，中间值减弱再平衡程度。也可在配置中设置 `balance_beta`，命令行优先。权重推导见[中性识别改进方案](中性识别改进方案.md)。三种对照首先保持额外中性倍率为1，避免同时改变两个因素。

修改训练超参数不会改写已保存检查点；当前正式路径已采用F1的seed2026权重，test ACC为72.63%。此前68.09%的测试ACC属于旧的未加权模型，不是新方案的已验证成绩。历史实验恢复时仍使用原协议：旧版本的 `balance_beta` 视为0，不会因当前配置改变而自动启用平衡。

## 额外调整中性倍率

`--neutral-weight` 在频数权重基础上额外乘到真实中性类别，再统一归一化，默认1.0。它参与完整视图和局部缺失视图的反向传播；仅在 `--balance-beta 0` 时退化为此前的 `[1,中性倍率,1]` 相对权重。

```bash
# 中性权重1.5，使用指定的五个seed
python run_problem2.py --seeds 2026 2027 2028 2029 2030 --balance-beta 0 --neutral-weight 1.5 --run-name neutral_w15 --device cuda:3

# 同一seed下做单独对照；每个实验使用新名字
python run_problem2.py --seed 2026 --balance-beta 0 --neutral-weight 1.0 --run-name neutral_baseline
python run_problem2.py --seed 2026 --balance-beta 0 --neutral-weight 1.25 --run-name neutral_w125
```

也可以在当前配置 `configs/problem2_bert_finetune.json` 中设置 `"neutral_weight": 1.5`。优先级为命令行参数高于配置文件；两者都未指定时为 1.0。要求有限正数；只有关闭频数平衡且倍率为1.0时，才精确保持原分类损失及梯度。

采用按真实类别加权的平滑交叉熵，并除以批次权重之和。保留原有 0.03 标签平滑，Huber 回归项和有序项不直接加权。公式和设计理由见[中性识别改进方案](中性识别改进方案.md)。提高权重会改变训练梯度，不能用推理偏置实验的负结果否定它。

首轮可比较 1.0、1.25、1.5、2.0，保持同一组seed和其他参数，以实际总体ACC、中性Precision/Recall/F1和局部缺失结果决定采用值。这只是待试验的范围，本次没有完成这些权重的完整训练，不能宣称某个值已经提高准确率。

## 每次运行结束看哪里

未指定名称时自动生成带微秒的时间戳，避免覆盖。指定名称时，若目录已存在则拒绝覆盖，请换名字或使用resume。

```text
CPMCM/
├── run_problem2.py
├── problem2/results/runs/<实验名或时间戳>/
│   ├── protocol.json                 # seeds、设备、参数与环境快照
│   ├── run.log                       # 控制台训练记录
│   ├── results.csv                   # 所有seed逐次指标及对应模型路径
│   ├── results.json
│   ├── summary.csv                   # 跨seed均值/样本标准差
│   ├── 结果说明.md                    # 可直接阅读的结果表
│   └── processed_po_seed42/
│       ├── history.json              # 每轮指标，含seed
│       ├── summary.json              # 训练摘要，含seed
│       ├── experiment_result.json    # 最终指标，含seed和权重SHA256
│       ├── valid_full.csv            # 逐条预测，含seed列
│       ├── valid_local30.csv
│       ├── test_full_seed42.csv      # 文件名和数据列均注明seed
│       └── test_local30_seed42.csv
└── AAAmodel/checkpoints/runs/<实验名或时间戳>/
    └── processed_po_seed42.pt
```

`results.csv`中重点看：

| 字段 | 含义 |
|---|---|
| `dataset` / `seed` | 数据版本和本次训练seed |
| `neutral_weight` | 频数平衡后的额外中性倍率 |
| `balance_beta` | 本次训练的频数平衡强度 |
| `train_class_counts` | 仅从train统计的负、中、正三类数量 |
| `class_weights` / `weight_negative` / `weight_neutral` / `weight_positive` | 实际使用的归一化三类权重 |
| `best_epoch` | 验证集选择的epoch |
| `valid_accuracy` | 完整验证集准确率 |
| `test_accuracy` | 你关心的完整测试集准确率 |
| `test_local30_accuracy` | 30%三模态连续局部缺失测试准确率 |
| `test_correct` / `test_samples` | 正确数量与样本数量 |
| `test_macro_f1` / `test_mae` / `test_pearson` | 分类、强度的其他指标 |
| `test_neutral_precision` / `test_neutral_recall` / `test_neutral_f1` | 完整测试集中性识别指标 |
| `test_local30_neutral_precision` / `test_local30_neutral_recall` / `test_local30_neutral_f1` | 局部缺失测试集中性识别指标 |
| `checkpoint` / `checkpoint_sha256` | 此seed对应的模型路径与身份 |

CSV准确率按0～1保存，例如0.6809表示68.09%；控制台和Markdown直接显示百分数。每个seed完成后立即刷新汇总，不必等待所有seed跑完。单seed无法估计跨seed标准差，`summary.csv`中留空，不填成0。

新实验的协议、检查点配置、训练日志、训练摘要与最终结果保存两个超参数、训练类数和实际三类权重；逐样本预测也保存超参数和三个权重列。汇总按数据版本、精度、beta和额外中性倍率分组，避免混合不同方案。历史未加权实验按beta=0、倍率=1读取，未知训练类数和未记录的中性指标不伪造补齐。

## 中断后继续

```bash
python run_problem2.py --resume problem2/results/runs/my_seeds
```

resume使用该目录保存的seed列表、数据版本、设备和训练参数，忽略本次其他训练参数。已完整完成的seed核对权重SHA后直接复用；训练完成但测试尚未完成的seed复用训练检查点补做测试；训练阶段尚未完成的seed从头训练，不声称恢复了中途优化器状态。

恢复时两个权重参数都使用已保存值；要更换参数，请启动新实验，不使用 `--resume`。发现已有结果或检查点的平衡强度、中性倍率、实际权重与保存记录不一致时拒绝复用。历史复用入口 `problem2.seed_experiment` 不用于新加权实验，请使用根目录总入口。

原正式权重不自动替换。你可以在汇总表中选想保留的seed，每个seed的权重都独立保存。脚本报告各次test结果，但不会保证某个seed达到70%，也不会把单次最高值写成跨seed平均成绩。

## 短程检查

```bash
python run_problem2.py --seed 7 --epochs 1 --patience 1 --run-name quick_check
```

这仅用于检查输入、训练、推理与结果输出；一轮训练成绩不代表完整方案效果。

## 温和平衡与中性边界训练

固定数据、seed和预算，分别改变平衡强度与边界权重，例如：

```bash
python run_problem2.py --seed 2026 --datasets processed_po --balance-beta 0.5 --neutral-weight 1 --boundary-weight 0.03 --boundary-margin 0.5 --boundary-max-intensity 0.5 --boundary-warmup-epochs 3 --run-name mild_boundary_example
```

当前配置的 `--boundary-weight` 默认0.1；设为0关闭。配置未设置时兼容默认0。0.03和0.1为本轮对照的最大权重。`--boundary-margin` 为排序间隔；`--boundary-max-intensity` 限定弱极性样本的真实强度绝对值上限；`--boundary-warmup-epochs` 为达到最大权重的轮数。第e轮实际权重是 λ×min(1,e/轮数)，所以最佳epoch较早时有效值可能小于配置值。

边界损失仅在训练集完整视图上计算，同批真实中性与弱正/弱负进行配对；没有可配对样本则返回零。局部缺失视图保持分类、回归、有序损失。推理仍使用三分类argmax，没有额外阈值或新分类头。

协议、检查点、逐轮日志、结果与逐样本表记录四个边界参数；训练摘要和最终结果额外记录最佳epoch的 `effective_boundary_weight`。汇总分组和恢复一致性检查包含边界参数，旧记录缺省为关闭边界训练。五组重点对照见 [实验对比](results/neutral_focus_seed2026/实验对比.md)。

## 训练集微调BERT

```bash
python run_problem2.py --config configs/problem2_bert_finetune.json --datasets processed_po --seed 2026 --device cuda:3 --epochs 12 --patience 4 --batch-size 16 --lr 0.0001 --balance-beta 0 --boundary-weight 0.1 --run-name bert_finetune_seed2026
```

配置里的 `finetune_bert=true` 开启在线逐槽BERT；`bert_lr=1e-5`、`gradient_accumulation=4` 控制文本学习率与梯度累积。`init_checkpoint` 为本题训练得到的融合层初始化；通用BERT从本地原始权重初始化。上面显式给出预算参数便于复现；总入口现在会继承配置中的预算，显式CLI参数才覆盖配置。改seed时同时改run-name，已存在目录用 `--resume`。

模型仍由 `problem2/model.py` 定义，训练沿用 `problem2/training.py`。在线模型跳过缺失文本特征缓存，并把BERT权重、文本缩放buffer及融合层一同保存；通过 `restore` 自动识别，附件3接口支持原token ID在线编码。该配置现已指向正式采用的β=0.25模型；以后新实验仍不自动替换正式权重。

保守微调对照可在上面命令中增加 `--bert-trainable-layers 4 --bert-lr 0.000002`，将 `--lr` 改为 `0.00002`，并使用新run-name。这会冻结词嵌入和底部8层，同时关闭冻结部分的dropout；顶部4层继续接受任务梯度。全量微调默认12层，pooler始终不参与逐槽任务。

## 微调＋边界＋更温和类别平衡

沿用微调入口，只调 `--balance-beta`；额外中性倍率保持1。例如：

```bash
python run_problem2.py --config configs/problem2_bert_finetune.json --datasets processed_po --seed 2026 --device cuda:3 --epochs 12 --patience 4 --batch-size 16 --lr 0.0001 --bert-lr 0.00001 --bert-trainable-layers 12 --boundary-weight 0.1 --balance-beta 0.1 --neutral-weight 1 --run-name my_bert_mild_beta010
```

将β改为0.25并换run-name即可运行另一组；β=0是取消类别加权的对照。三种机制已在现有模型和训练入口中组合，无需另建模型模块。本轮结果和最终组合配置见[组合实验报告](results/bert_mild_balance_seed2026/实验报告.md)。

本轮已采用β=0.25作为三项组合的默认训练配置。最简运行命令：

```bash
python run_problem2.py --seed 2026 --run-name my_bert_boundary_mild
```

β=0.25的现有候选测试ACC为68.91%，与不加权微调方案持平；中性指标和局部缺失指标的取舍见组合报告。用户已正式确认采用，正式推理权重与 `configs/problem2_aligned.json` 已同步；默认 `python -m problem2.problem2 predict` 即使用该方案。旧正式权重已归档。
