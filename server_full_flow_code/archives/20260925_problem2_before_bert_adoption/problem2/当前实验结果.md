# 当前实验结果（2026-09-25）

所有候选使用通用BERT逐槽特征，训练与选模不读取test。原情感预训练/CLS广播模型成绩不作新模型成绩。

| 输入 | 架构 | 完整验证Acc | 局部30%验证Acc | 选择分数 | 最佳epoch |
|---|---|---:|---:|---:|---:|
| processed | pooled | 64.15% | 58.93% | 0.6258 | 3 |
| processed | cross_attention | 64.42% | 58.93% | 0.6277 | 2 |
| processed_po | pooled | 63.60% | 59.62% | 0.6240 | 3 |
| processed_po | cross_attention | 64.84% | 59.89% | 0.6335 | 2 |

选中 **processed_po / cross_attention**，可训练参数 328,331，训练设备 cuda:3（NVIDIA GeForce RTX 4090）。本轮是两个不等价数据版本×两种架构、各一个种子的比较，不宣称全局最优。

冻结后的完整test Accuracy为 **68.09%（495/727）**，Macro-F1=0.6036，MAE=0.6310，Pearson=0.6686。
30%三模态局部缺失test Accuracy为 **66.02%（480/727）**，MAE=0.6686。

**尚未达到此前70%的目标。** 本轮test没有参与候选选择；该划分历史上已被使用，不称为全新外部测试集。不同完整/缺失场景必须分别报告，不能把较高的完整观测成绩套到缺失场景。
