# 借鉴图文融合仓库的三模态优化实验

## 目标与实验约束

目标为附件2测试集完整观测三分类Accuracy约75%。训练3395条，valid 728条，test 727条，保持原始视频分组隔离。valid用于候选/epoch选择，先冻结再评价test；不改标签、不删中性类。原模型test 514/727=70.7015%已知，作为保留基线。

参考提交为YeexiaoZheng/Multimodal-Sentiment-Analysis的3745ef924f800dd462cddd2179d09c11cca9f140，借鉴全局特征投影、拼接融合、预训练骨干低学习率。其图文数据与本题不同，不直接照搬ResNet50，也不复制其序列长度为1的注意力张量布局。

## 全局融合公式与代码对应

设编码后的观测特征为 $x_{m,t}$、实际可见掩码为 $M_{m,t}$。所有统计量先将隐藏位置置零，只使用可见值：

$$n_m=\max(1,\sum_t M_{m,t}),\quad
\mu_m=\frac{\sum_t M_{m,t}x_{m,t}}{n_m},\quad
\sigma_m=\sqrt{\frac{\sum_t M_{m,t}(x_{m,t}-\mu_m)^2}{n_m}+10^{-6}}.$$

全缺失模态的标准差强制为0。文本为句级语义，只取均值；音频、视觉拼接均值和标准差。分别经Linear、LayerNorm、GELU投影至64维，得到三个模态表示 $z_m$。定义可用标记 $a_m=1[n_m^{raw}>0]$，投影后再次乘 $a_m$，避免缺失模态的投影偏置成为伪证据。

拼接版本将 $u=[z_T;z_A;z_V]$ 输入残差前馈：

$$r=W_o\operatorname{Dropout}(\operatorname{LN}[u+F(\operatorname{LN}(u))])+b_o,$$

其中F为192→192→192的GELU前馈网络。新分支输出4维，分别为三类logit及回归pre-tanh残差：$s=s_{old}+r$。输出层初始化为0，保证训练开始时与旧模型等价。全模态缺失时r=0。它是独立的句级联合贡献，不能伪称逐窗口贡献。

注意力版本先将 $[z_T,z_A,z_V]$ 组织成[B,3,64]，加入模态嵌入，通过一层4头Transformer，再按模态拼接。key padding mask屏蔽无观测模态；全空时临时开放空token以避免NaN，再把结果清零。注意力在真正的三模态轴计算。

单模态辅助监督使用 $\ell_m=C_m(z_m)$，只对可用模态求交叉熵均值：

$$L_{aux}=\frac{\sum_{i,m}a_{i,m}\operatorname{CE}(\ell_{i,m},y_i)}{\sum_{i,m}a_{i,m}}.$$

总目标沿用原完整分类/回归、缺失任务和重建损失，启用辅助项时添加 $0.15[L_{aux}^{full}+\lambda_{miss}L_{aux}^{missing}]$。没有把softmax概率送入交叉熵。

## 五个候选与算法差异

| 候选 | 改变机制 |
|---|---|
| ote_global_concat | 句级全局拼接残差；旧模块/LoRA/新融合分别设置学习率 |
| ote_modality_attention | 将拼接前的三个模态作为token，使用正确维度的注意力 |
| ote_global_aux | 拼接版本增加单模态辅助分类监督 |
| ote_domain_finetune | 辅助监督版本进一步解冻已有RoBERTa最后两层及情感分类头，学习率5e-6；不扩大骨干 |
| ote_frozen_fusion | 旧模块与LoRA学习率置0，仅更新全局融合；关闭旧模块训练Dropout，融合Dropout为0.5，减轻联合更新破坏已有表征 |

每个候选最多30 epoch、8轮未改善早停；候选输出独立，不覆盖main。训练及验证使用物理GPU2/3，进程内CUDA_VISIBLE_DEVICES映射为逻辑cuda:0。

实验实现分为global_fusion.py、model.py、training.py、training_step.py（现已归档至archives/global_fusion_trial/trial_code/problem2）；统计量、融合和辅助损失分别有明确职责。隐藏值替换不影响输出、全缺失有限、初始化残差为0、反向传播检查均通过。新增联合模型账本重建检查后，实验版完整测试30项通过，日志为logs/tests_global_fusion.log。

## 结果

| 候选 | 最佳epoch（从0计） | 完成epoch | valid正确数 | valid Accuracy |
|---|---:|---:|---:|---:|
| ote_global_concat | 4 | 13 | 489/728 | 67.1703% |
| ote_modality_attention | 1 | 10 | 494/728 | 67.8571% |
| ote_global_aux | 0 | 9 | 491/728 | 67.4451% |
| ote_domain_finetune | 3 | 12 | 499/728 | 68.5440% |
| ote_frozen_fusion | 3 | 12 | 490/728 | 67.3077% |

按valid选出的ote_domain_finetune在训练结束后冻结，冻结时间和权重SHA256见results/ote_trials/frozen_selection.json；仅该候选读取test一次。其结果为：

| 指标 | 原模型 | 最佳新候选 |
|---|---:|---:|
| valid Accuracy | 68.2692%（497/728） | 68.5440%（499/728） |
| test Accuracy | **70.7015%（514/727）** | 70.2889%（511/727） |
| test Macro-F1 | 0.613358 | 0.620341 |
| test MAE | 0.593854 | 0.594203 |
| test Pearson | 0.722455 | 0.738284 |

验证集纠正13条、同时新增11条错误，净增2条；中性类召回由50/184提高至54/184，仍然偏低。测试集Accuracy退回3条，不能将Macro-F1/Pearson的小幅提升当作Accuracy目标达成，也不能把验证提升外推为测试提升。

**结论：约75%的新目标未达到，正式模型保留原70.7015%版本。** 候选按valid选择，最终是否替换主模型则参考了冻结候选与已知基线的test结果；这不是完全未触及测试集的盲测流程。测试后没有继续调参。
