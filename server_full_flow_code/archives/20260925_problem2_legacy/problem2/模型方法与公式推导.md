# 问题二：缺失条件下的多模态情感识别——模型方法与公式推导

阅读入口：[模型架构与逐层推导](问题二建模思路说明.md)。该说明按实际计算顺序展开输入维度、模块连接及公式来源；本文保留完整方法索引。

> 问题二当前更新：专项配置为 `configs/problem2_robust.json`，同条件消融选中保留补全、关闭可靠性门控的版本，最终强度采用按极性的可行域投影。168组局部缺失验证及附件3全量30条已完成，详见[本次完整说明](局部缺失建模与题意核对.md)。下文原模型参数与70.70%结果作为此前共享架构/完整准确率路线记录；问题三仍使用原main模型。

> 最新目标与结果：用户将测试集目标提高到约75%。借鉴第一个参考仓库完成五组实验后，最佳新候选test为70.2889%，低于原模型70.7015%，已归档并恢复原模型；**75%目标尚未达到**。详见[全局融合优化记录](全局融合优化记录.md)。

本文对应 `configs/final.json` 与当前 `model.py`，不是把所有实验选项合写成一个已运行模型。完整链路为：附件特征 → 区分位置与观测 → 编码 → 观测条件补全 → 可靠性门控 → 窗口聚合 → 加性预测 → 完整/遮挡联合训练。

## 1. 问题与建模边界

每条样本包含文本、音频、视觉，目标同时为负/中/正三分类及 $[-3,3]$ 连续情感强度。输入可能原本缺失，也可能在训练、评估中人为删除连续片段。核心要求是删除的信息不能再从编码、缓存或补全中读回。

附件2提供对齐版本；本文沿用其50个位置，不重新推断官方真实词边界。问题一所采用的原媒体质量规则用于附件1，不能由附件2预提取向量反推出原波形RMS或人脸置信度。三个模态的全零行是缺失代理，不是经过人工认证的无效标签。

## 2. 变量与张量

| 符号 | 维度/取值 | 代码 |

| $n$ | 样本编号 | batch维 |
| $m\in\{T,A,V\}$ | 模态 | 0、1、2 |
| $t=0,\ldots,49$ | 输入槽 | 时间维；不自动等于秒 |
| $X^A,X^V$ | $50\times74,50\times35$ | audio、vision |
| $U$ | $3\times50$ | tokens；ID、attention、segment |
| $P,O,B,M$ | $3\times50$布尔数组 | 有效范围、原观测、人工保留、实际观测 |
| $d$ | 64 | hidden |
| $\mu,\ell$ | 各模态原特征维度 | mean、logvar |
| $q$ | $3\times50$ | reliability门控后的权重 |

| $s,\hat y$ | 标量 | score、intensity |

训练数据的分类标签须满足 $c=\operatorname{sign}(y)+1$；代码发现不一致会报错。分类输出用三个logit的argmax，回归输出单独约束范围；不强制两者符号一致，另报告不一致率。

## 3. 从原始可用性到实际观测掩码

### 3.1 原始观测

文本排除PAD、CLS、SEP：

$$O^T_t=\mathbf1\{a_t=1\}\mathbf1\{u_t\notin\{0,101,102\}\}.$$

附件所有特征首先通过有限性与形状校验，随后对音视频使用

$$O^m_t=\mathbf1\{\exists j:X^m_{tj}\ne0\},\quad m\in\{A,V\}.$$

这不能区分真实零向量与缺失编码，因此结果携带 `validity_uncertain=True`。

### 3.2 有效范围

`union_extent`先令 $S_t=(a_t>0)\lor O^A_t\lor O^V_t$，再令

$$t_* = \max\{t:S_t=1\},\quad p_t=\mathbf1\{t\le t_*\}.$$

集合为空时所有 $p_t=0$。音视频的 $P^m=p$；文本还排除CLS和SEP位置。最后把 $O$ 与 $P$ 相交。注意内部PAD可能在范围内但不可观测；它不是已观测文本。该范围是输入元数据不足时的假设，应与 `attention_extent`、`all_slots` 作敏感性比较。

### 3.3 人工缺失

$$\boxed{M=P\odot O\odot B} \tag{2-1}$$

完整输入取 $B=1$。人工连续遮挡从有效范围中选择长度约为 $\operatorname{round}(r\sum_tP_{mt})$ 的区间，把对应 $B$ 置0；不是把不连续的有效位置压缩后再遮挡。原本缺失的槽不因人为遮挡变成监督真值。

$$H=P\odot O\odot(1-M) \tag{2-2}$$

$H$ 是“原来有真值、现在被人为隐藏”的重建监督集合。对应 `shared/data.py::block_mask` 与 `losses.py::objective`。

## 4. 特征编码与防止文本泄漏

### 4.1 音视频标准化

只在train中原本观测到的行拟合每维均值与方差：

$$\bar x_j=\frac1{N}\sum_{(n,t):O_{nt}=1}x_{ntj},\quad
\sigma_j=\sqrt{\max\left(\frac1N\sum x_{ntj}^2-\bar x_j^2,10^{-8}\right)}.$$

最终使用

$$v^m_t=M^m_t\,\operatorname{clip}\left((X^m_t-\bar x^m)/\sigma^m,-5,5\right). \tag{2-3}$$

统计量随checkpoint保存，valid/test/附件3/4只复用，不重新估计。

### 4.2 当前文本编码器

输入仍是官方BERT词元。`SentimentEncoder`先按当前 $M^T$ 删除不可观测ID，再由原BERT分词器解码保留内容，使用本地三分类RoBERTa重新分词。不会从 `raw_text` 恢复已删除词，也不先编码完整句子再遮掉向量。

令保留内容经骨干得到句级向量 $h_{CLS}\in\mathbb R^{768}$ 和负/中/正先验logit $r\in\mathbb R^3$，则

$$g=[\operatorname{LN}(h_{CLS})_{1:765};r_1;r_2;r_3],\quad
v^T_t=M^T_tg. \tag{2-4}$$

这是“765维句级语义+3维分类先验”广播到保留位置，不是每词独立的768维上下文向量。源码 `feature[:,-3:]=result.logits` 与公式一致；因此局部删除必须重新编码整句，不能把广播向量当局部词证据。

### 4.3 低秩适配

对选中的线性映射 $W$ 添加

$$Wx\longmapsto Wx+\frac\alpha r BAx,\quad A\in\mathbb R^{r\times d_{in}},B\in\mathbb R^{d_{out}\times r}. \tag{2-5}$$

最终配置在最后6层query/value上使用 $r=4,\alpha=8$。骨干原权重冻结，仅训练低秩增量及下游网络；启用骨干dropout。它减少可训练参数，但外部RoBERTa与原BERT总参数数并不完全相同，不能写成“总模型规模完全不变”。

## 5. 仅读取保留观测的条件补全

### 5.1 投影与记忆

各模态投影到64维：

$$e^m_t=\operatorname{Dropout}(\operatorname{GELU}(W_m v^m_t+b_m)),\quad
k^m_t=e^m_t+p_t^{emb}+a_m^{emb}. \tag{2-6}$$

注意位置嵌入 $p_t^{emb}$ 不同于布尔掩码 $P$。150个位置组成memory，但attention的key padding mask禁止读取 $M=0$ 的位置，不能仅靠把值置零来屏蔽偏置/位置嵌入。

初始查询为

$$Q^0_{mt}=p_t^{emb}+a_m^{emb}+u_m.$$

当前最终配置没有启用实验性 `contextual_fusion`，查询不附加输入内容。若样本三个模态完全没有观测，仅开放一个可学习null记忆，避免全mask softmax出现非有限值；此时输出属于先验预测，标记low_evidence。

### 5.2 交叉注意力

一头attention为

$$A=\operatorname{softmax}\left(\frac{QW_Q(KW_K)^\top}{\sqrt{d_h}}+\mathcal A_M\right),\quad Z=A(KW_V), \tag{2-7}$$

不可读取位置的 $\mathcal A_M=-\infty$。多头拼接投影后，执行

$$\widetilde Q=\operatorname{LN}(Q+\operatorname{MHA}(Q,K,K)),\quad
Q'=\operatorname{LN}(\widetilde Q+\operatorname{FFN}(\widetilde Q)). \tag{2-8}$$

最终为2层、4头；每层memory始终是原保留观测。前一层的预测不写回memory，不把猜测当作新观测反复增强。

### 5.3 均值、方差与高斯重建

对最后一层查询分别预测

$$\mu^m_t=W^m_\mu Q^m_t+b^m_\mu,\quad
\ell^m_t=\operatorname{clip}(W^m_\ell Q^m_t+b^m_\ell,-6,4),\quad
(\sigma^m_t)^2=\exp\ell^m_t. \tag{2-9}$$

对角高斯假设下，单维条件密度为

$$p(x\mid X_{obs})=(2\pi e^\ell)^{-1/2}\exp[-(x-\mu)^2/(2e^\ell)].$$

取负对数并去掉与参数无关的 $\frac12\log2\pi$，得到

$$\mathcal L_{NLL}(x,\mu,\ell)=\frac12[(x-\mu)^2e^{-\ell}+\ell]. \tag{2-10}$$

前项处罚相对于方差的误差，后项抑制无限增大方差来逃避误差。源码先对每个有隐藏真值的模态的 $H$ 位置和特征维平均，再对这些模态平均；不是把全部维度拼接后统一平均。文本目标取完整分支的编码并detach，因此会随训练适配器变化，并非静态人工语义真值。

## 6. 由预测方差得到补全可靠性

令 $d_m$ 是原特征宽度，定义

$$\rho^m_t=\exp\left[-\frac1{\tau_m d_m}\sum_{j=1}^{d_m}\exp(\ell^m_{tj})\right],\quad\tau_m=1. \tag{2-11}$$

该映射将非负平均方差映射到 $(0,1]$；其导数对方差为负，方差越大，补全贡献越小。这是设计的门控规则，不是已校准的“预测正确概率”。

$$q^m_t=P^m_t[M^m_t+(1-M^m_t)\rho^m_t],$$

$$h^m_t=M^m_te^m_t+P^m_t(1-M^m_t)q^m_t\operatorname{GELU}(W_m\mu^m_t+b_m). \tag{2-12}$$

真实观测权重为1，补全槽乘可靠性，填充槽归零。补全与真实输入共享模态投影。`no_reliability`把 $\rho$ 设为1；`no_completion`把它设为0并停用重建损失。后一消融仍保留缺失标记，不能描述成“完全不知道缺失”。

## 7. 固定窗口聚合与加性决策

### 7.1 聚合

50槽按宽度5分成10窗。拼接状态得到67维：

$$a^m_t=[h^m_t;M^m_t;P^m_t(1-M^m_t);q^m_t].$$

$$u^m_w=\frac{\sum_{t\in W_w}P^m_ta^m_t}{\max(1,\sum_{t\in W_w}P^m_t)}. \tag{2-13}$$

分母使用有效槽数，不仅是观测槽数；因此保留缺失比例信息。编码开始前在train上求固定窗口背景 $u^0_{mw}$，随checkpoint保存，训练中不反复更新背景。

### 7.2 中心化单模态与两两交互

每个小网络输出4维，前三维分类、第四维回归原始分数：

$$F_{mw}=f_m(u^m_w)-f_m(u^0_{mw}),$$

$$G_{ab,w}=g_{ab}([u^a_w;u^b_w])-g_{ab}([u^0_{aw};u^0_{bw}]). \tag{2-14}$$

$f,g$ 都是线性→Tanh→线性网络。中心化使“当前表征与固定背景相同”时该项为0，但不保证两两项纯粹正交于单项；它不是统计ANOVA唯一分解。

令 $I_{mw}$ 表示该窗至少有一个有效槽，则

$$\alpha_{mw}=\frac{I_{mw}}{\max(1,\sum_w I_{mw})},\quad
\beta_{ab,w}=\frac{I_{aw}I_{bw}}{\max(1,\sum_w I_{aw}I_{bw})}. \tag{2-15}$$

代码从聚合后的观测/缺失标记判断 $I$。该归一化避免有效窗口越多，分数仅因累加项增多而扩大。

### 7.3 显式文本先验与最终输出

$$R=[\operatorname{mean}_{t:M^T_t=1}(v^T_{t,-3:});0],$$

无保留文本时 $R=0$。最终先验缩放为1，计算

$$\boxed{[z_0,z_1,z_2,s]=b+R+\sum_{m,w}\alpha_{mw}F_{mw}+\sum_{a<b,w}\beta_{ab,w}G_{ab,w}}. \tag{2-16}$$

$$p_c=\frac{e^{z_c}}{\sum_j e^{z_j}},\quad\hat c=\arg\max_c z_c,\quad\hat y=3\tanh(s). \tag{2-17}$$

softmax来自对三个logit指数归一化；tanh将任意实数分数连续映射到 $(-3,3)$。分类不能用回归符号替代。最终没有启用三阶交互或双向GRU；相应代码仅作为已尝试的实验扩展。

## 8. 联合目标及求解

### 8.1 任务监督

平滑标签 $\widetilde y_k=(1-\epsilon)\mathbf1\{k=c\}+\epsilon/3$，当前 $\epsilon=0.05$、类别权重均为1：

$$\mathcal L_{CE}=-\sum_{k=0}^2\widetilde y_k\log p_k.$$

Huber令 $e=\hat y-y$，转折点1：

$$h(e)=\begin{cases}\tfrac12e^2,&|e|\le1,\\ |e|-\tfrac12,&|e|>1.\end{cases}$$

小误差平滑平方、大误差线性增长，减弱异常强度标签影响。当前

$$\mathcal L_{task}=\mathcal L_{CE}+0.2\operatorname{mean}h(\hat y-y). \tag{2-18}$$

### 8.2 完整与缺失分支

$$\mathcal L=\mathcal L_{task}^{full}+\lambda_{miss}\mathcal L_{task}^{miss}
+\lambda_{rec}\mathcal L_{NLL}+\lambda_{con}\mathcal L_{con}. \tag{2-19}$$

实现的一致性项为

$$\mathcal L_{con}=D_{KL}(\operatorname{stopgrad}p^{full}\Vert p^{miss})+
\operatorname{MSE}(\hat y^{miss},\operatorname{stopgrad}\hat y^{full}).$$

但最终 **$\lambda_{con}=0$**，因此本次模型不能宣称使用一致性正则取得指标；同样Mixup、监督对比、EMA均未在最终方案启用。

最终 $\lambda_{miss}=0.15,\lambda_{rec}=0.02$，前8轮乘 $\min(1,(epoch+1)/8)$ 逐步增强缺失训练。训练随机选择七种非空模态组合与10%、30%、50%连续遮挡率。

### 8.3 优化与停止

AdamW，主体学习率 $4\times10^{-4}$、适配器 $5\times10^{-5}$、weight decay=0.05；梯度范数裁剪1；batch64，最多40轮，12轮未改进早停，验证停滞时减半学习率。

验证选择分数为

$$J=-Acc_{full}-10^{-4}Acc_{miss}+10^{-6}MAE_{full}. \tag{2-20}$$

较小更好：以完整观测Accuracy为主，其他项破近似同分。标准化、背景和参数梯度都只来自train；valid参与选模因此不是完全未见的最终检验，test在本轮方案冻结后评价。本轮开始前已有上一轮测试结果可知，记录在冻结文件中，不能把整个多轮研究描述成从未查看过测试集。

## 9. 评价公式与实际结果

$$Acc=\frac1N\sum_n\mathbf1\{\hat c_n=c_n\},\quad
MAE=\frac1N\sum_n|\hat y_n-y_n|.$$

$$F1_k=\frac{2TP_k}{2TP_k+FP_k+FN_k},\quad MacroF1=\frac13\sum_kF1_k.$$

分母为0时该类F1取0。Weighted-F1按真实类样本数加权；Pearson用预测与真值中心化后的内积除以范数乘积，常量序列时记不可用。95%区间按原视频ID分组bootstrap500次，整组重采样，减少同视频片段相关导致的虚假精确。

| 完整观测 | N | Accuracy | Macro-F1 | MAE |
|---|---:|---:|---:|---:|
| valid | 728 | 68.2692% | 0.624168 | 0.551775 |
| test | 727 | 70.7015% | 0.613358 | 0.593854 |

来源为 `results/main/{valid,test}/metrics.json`，不是训练准确率。测试集点估计70.7015%已达到用户明确的测试集70%验收目标；验证集68.2692%用于选模，此前将其误作验收门槛；测试Accuracy的分组95%区间约为[67.09%,74.09%]，不构成总体准确率一定超过70%的保证。中性样本保留，三分类定义未更改。

## 10. 检验、灵敏度与限制

- 缺失检验：完整输入、七种模态组合、不同连续缺失比例和位置；报告实际新增隐藏数，不能仅报请求比例。
- 消融：关闭补全、关闭可靠性。旧轮次消融不能直接当新文本骨干的消融证据；运行配置和主模型应相同，仅改被检验项。
- 灵敏度：有效范围假设、窗口宽度、$\tau$、缺失权重与随机种子。实验代码存在不等于已完成所有实验。
- 方差检验：比较不同可靠性组的隐藏重建误差；低方差不自动证明情感分类更准确。
- 文本限制：重分词后句级广播增强情感先验，同时牺牲直接词级隐藏状态解释；须由问题三实际删除重算给证据。
- 补全限制：自然缺失没有真值；人工缺失重建效果不能等同于自然缺失恢复正确率。
