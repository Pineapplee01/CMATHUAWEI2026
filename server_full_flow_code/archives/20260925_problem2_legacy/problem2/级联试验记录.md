# 级联中性检测试验记录（DeBERTa 方案，2026-09-24）

> 结论：**级联方案在现有特征集上没有可用的独立增益，未对 test 执行读数，主模型保持 70.7015% 不变。**
> 本轮价值：把"中性检测是否有救"从猜想变成了实测否定，并给出完整证据链。

## 实测事实

### 1. 上传的 DeBERTa-v3-large 是 MLM 预训练底座，无情感分类头

config 无 num_labels/classifier，句向量（CLS 与均值池化都试了）在 train 上分组CV三分类仅 38-39%，中性概率对真中性/真极性几乎无差（0.339 vs 0.330 基率）。**它不能作为情感先验**。改用项目内已有的 cardiffnlp twitter-roberta（有真三分类头，零样本 test 中性召回 75.9%）作为先验源。

### 2. 中性可分性 AUC 审计（train 按视频分组5折，诚实 held-out）

| 证据源（单独） | CV-AUC |
|---|---:|
| 主模型 log_neu | **0.7630** |
| cardiffnlp prior_neu | 0.7141 |
| log_neu + prior_neu 最优组合 | 0.7695 |
| 全部7特征组合 | 0.7762 |
| + TF-IDF 词元n-gram（单独 0.635） | 0.7762 |
| DeBERTa MLM 嵌入 | ≈随机 |
| 未对齐500槽 A/V 时序统计 | 0.5508 |

**关键事实：主模型自己的 log_neu 已经是最强中性证据，先验与之高度相关，叠加所有外部证据仅 +0.013 AUC。** 这推翻了此前"零样本先验互补性强"的判断——混淆矩阵上的互补是阈值效应，在概率层面不存在独立信息。

### 3. 决策规则诚实评估（train CV，未触碰 valid/test）

| 规则 | 最优 train CV |
|---|---:|
| plain argmax（基线） | 0.7175 |
| 硬级联 demote→argmax(负,正) | 0.7087（低于基线） |
| 单调中性偏移 k·(g−0.5) | 无增益 |
| valid 上 oracle-eta（用真值挑最好阈值） | 0.644，仍低于 valid 基线 0.683 |

valid 上 12 个历史模型全组合等权 logit 集成最高 0.6854（基线 0.6827），+0.27 个点在 728 条样本噪声内。

### 4. 纪律

`cascade.py --freeze`（唯一一次 test 读数）**未执行**——valid 上无增益，按协议不读 test。`cascade_report.json` 保留完整 eta 网格与 valid 基线对比供复核。

## 软标签重训（方案C，2026-09-24，负结果）

训练前诊断确认了动机：主模型**在train上中性召回也仅29.3%**（不是泛化问题而是硬标签自相矛盾：y=±0.17标极性与内容相同的y=0标中性冲突），且 log_neu 的真中性/弱极性分离从train的0.260缩水到valid的0.096。

按 |强度| 连续软化的三个变体（软标签权重=sigmoid((δ−|y|)/T)·上限截断，B变体再乘cardiffnlp中性概率；真中性样本不受影响）：

| 变体 | δ / T / 上限 | best valid | 中性召回（基线0.272） |
|---|---|---:|---:|
| soft_label | 0.5 / 0.15 / 0.6 | 62.50% | 0.576 |
| soft_label_prior | 0.5 / 0.15 / 0.6 +先验 | 63.87% | — |
| soft_label_tight | 0.33 / 0.10 / 0.5 | 65.11% | 0.527 |

机制按设计工作（中性召回翻倍、预测中性占比升至29.7-35.2%），但极性侧召回损失更大（负类0.78→0.57-0.67，正类0.88→0.69-0.71），总体全部低于基线 68.27%。更关键的两个否定性实测：

- 软标签模型的中性 logit AUC 反而更低（A 0.680 / C 0.695，主模型 0.713）——软化监督没有产出更干净的中性表征；
- 与主模型 logit 等权集成（w=0.2..0.5、三模型平均）最高 0.6799，仍低于基线；中性 bonus/阈值扫描同样无增益。

按协议不读test，主模型不变。检查点在 `AAAmodel/checkpoints/archive/soft_label_trial/`，配置随源码快照归档。

## 对 75% 目标的最终判断（本轮更新）

事后决策层与监督侧软化均已实测排除。剩余未试方向只有特征侧：NLI/情感微调过的强文本骨干（当前上传的 DeBERTa 为 MLM 底座不可用，需联网获取）、64词元窗口。预期均为 +0.5~1.5 个点量级；在727条test、bootstrap 95% CI 宽7个点的条件下，75% 与 70.7% 的差异（+4.3个点）需要真实泛化增益而非选择效应，当前证据链不支持任何单步承诺。

## 区间化家族补测（2026-09-24，应用户"中性应为区间"的观点，负结果）

评测标签固定（valid/test 中性全部 y=0，来自比赛的 sign 约定），"区间化"只能发生在训练目标层。在三个 sigmoid 软标签变体之外，补测了该家族剩余两个变体：

| 变体 | 机制 | best valid | 对照基线 68.27% |
|---|---|---:|---:|
| 高斯软标签（用户精确公式 γ=0.42, k=1） | y_soft_neu=exp(−y²/2γ²) 全体连续软化 | **56.73%** | −11.54pt |
| 硬区间重标注（δ=0.35，仅train） | \|y\|≤δ 的 689 条直接划入中性（中性类 758→1447） | **60.16%**（epoch 0 即最佳） | −8.11pt |

高斯公式按预期比 sigmoid 更激进（y=+0.333 的真阳性拿到 73% 中性目标），结果最差；硬重标注在第一个 epoch 后一路变差，说明区间化目标与评测标签的矛盾随训练放大。五个变体（含此前三个）全部为负，机制一致：区间内非中性样本在 valid 占 20.2%（147/728）、test 占 17.9%（130/727），基线对它们的正确率约 82%，每次翻转都是净亏损，而中性召回收益（上限约 +56 条）不足以覆盖。

实现以默认关闭的选项保留：`losses.py` 的 `soft_label_gamma` 分支、`training.py` 的 `relabel_neutral_interval` 分支；配置与检查点归档于 `configs/archive/`、`AAAmodel/checkpoints/archive/interval_label_trial/`。测试 31 项通过。

## 模块4错误归因的实测验证（2026-09-24）

**发现2（缺失场景中性退化最重）被证伪，方向相反**：30% 随机缺失下中性是唯一提升的类（test 召回 0.203→0.329，valid +4.3pt），负/正类分别退化 −13.0/−9.4pt（test）；中性误判为正的比例由 58.2% 降至 44.9%。模型在证据缺失时变得更保守（向中性收敛）而非"幻觉极性"——这反而是不确定性门控补全有效性的直接证据。

**发现1（视觉礼貌性微笑驱动中性误判为正）在其具体形式上被证伪**：加性账本逐模态分解（valid，中性误判为正 n=100 对照正确中性 n=50）显示，误判样本的正类贡献主驱动是**文本模态**（+0.442，86% 样本文本在推正），视觉仅 +0.015（两组差异 +0.093）；且误判样本的可靠性 q 更高（0.47 vs 0.33），属"自信地错"。文本先验对中性语句的极性倾向才是根源。

论文可用结论：动态模态权重的必要性叙事成立，但需要调节的对象是文本先验而非视觉微笑；缺失场景的章节应按实测方向改写为"门控补全促使模型在证据缺失时保守化"。

## δ∈(0,0.17] 细搜索（2026-09-24，应用户要求，无更优解）

数据粒度事实：训练集 0<|y|<1/6 的样本为零（±1/6 带仅 2 条），故硬重标注在 (0,0.167) 可证明等价于基线；δ=0.17 实测 68.13%（移动 2 条，与基线差 1 条样本）。该区间的有效插值在软标签族：高斯 γ=0.10（±1/6 带 25% 中性权重、±1/3 带 0.4%）与 γ=0.17（62% / 14.6%）。

| 参数 | best valid | 对照基线 |
|---|---:|---:|
| γ=0.10 | 66.07% | −2.20pt |
| γ=0.17 | 65.52% | −2.75pt |

至此区间化家族共 8 个实测点（3 sigmoid + 3 高斯 + 硬 δ=0.17/0.35/0.67 加基线）：两族均随带宽参数增大单调恶化，向基线单调收敛但无任何交叉点。区间化最优解即退化点 δ→0（基线本身）。完整曲线见 `problem2/figures/delta_sweep.png`、数据 `results/delta_sweep.csv`、脚本 `plot_delta_sweep.py`。
