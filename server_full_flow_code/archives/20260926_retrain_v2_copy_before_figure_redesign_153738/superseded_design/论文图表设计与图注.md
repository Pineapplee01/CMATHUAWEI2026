# 连续局部模态缺失：六组消融的论文图表设计

本文件是结合代码审查制定的实验与绘图设计，不是实验结果报告。当前副本的旧五组结果不满足新六组矩阵；下列图均须由新实验产生。所有“论证目标”都是待检验的问题，不能在得到数据前写成已证实的结论。

## 一、代码事实与实验定义

现有对齐模型：BERT全量微调 → 三模态投影 → 观测条件补全与可靠性 → 每模态均值池化 → 样本级模态门控加权求和 → 分类、回归头。

现有未对齐模型：50个文本槽查询500帧音频、500帧视觉；使用连续单调窗口、窗内内容注意力和时间惩罚 → 每模态池化 → 样本级门控 → 分类、回归头。局部时间窗是归纳偏置，不等同于真实词帧对应标签。

代码中的旧B0/noC/noQ/noB/noBeta是逐项拆除实验；其中未对齐noC/noQ分别关闭局部窗、时间惩罚，不是重构、一致性。当前训练目标没有独立的完整—缺失一致性损失及显式隐空间重构监督。对齐代码虽返回补全特征，也不能据此声称已实现新矩阵中的“重构模型”。

### 六组矩阵及公平对照

| 编号 | 名称 | 测试输入 | G门控 | C一致性 | R重构 |
|---|---|---|---:|---:|---:|
| B_full | 完整基线 | 完整 | 0 | 0 | 0 |
| B_miss | 缺失基线 | 连续局部缺失 | 0 | 0 | 0 |
| G | 门控模型 | 与B_miss相同的缺失掩码 | 1 | 0 | 0 |
| C | 一致性模型 | 同上 | 0 | 1 | 0 |
| R | 重构模型 | 同上 | 0 | 0 | 1 |
| ALL | 完整模型 | 同上 | 1 | 1 | 1 |

为把“自然退化”归因于输入缺失，B_full与B_miss必须是同一基线检查点的两种测试视图，而不是分别训练后相减。因此六个评估组对应每seed五个训练变体。所有训练变体使用同样的完整/缺失数据增强、基础分类/回归/边界损失、类别权重和早停规则；C、R训练时可使用训练样本的完整视图监督，测试时只能读取缺失视图。

完整输入基线是性能参考，不是数学上必然的上界；若ALL超过它，应如实呈现。ALL对比B_miss同时变化三项，仅说明联合效果，不满足“单变量”；单模块归因依据G/C/R各自对比B_miss。六组不足以识别全部两两交互或证明协同效应，需要额外组合实验才可做这种结论。

### 为实现新矩阵需要的代码调整（尚未执行）

1. 无门控的基线必须真正使用拼接。为控制融合头差异，建议统一维度为3d，G使用`[3α_T h_T; 3α_A h_A; 3α_V h_V]`，无G使用`[h_T;h_A;h_V]`，其后共用相同结构的分类/回归头。均匀权重时两者输入一致。当前v2的加权求和得到d维，不能直接与3d拼接比较后把全部收益归因于门控。这一受控门控版本须重新训练，不能复用v2权重或宣称完全等同于旧v2。
2. 无R时关闭学习补全、可靠性补偿，缺失槽只保留约定的零值/掩码；R与ALL启用同一重构模块。在未对齐支路中，先明确重构的原生时间轴和目标空间，不能把50槽重构输出直接与500帧目标逐项比较。
3. C与ALL使用相同的显式一致性项；R与ALL使用相同的重构项。其系数只在验证集选择。边界λ=0.1、类别平衡β=0.25、BERT微调策略在所有组固定。
4. 对齐和未对齐分别做完整矩阵、分别汇总，不混成一个均值。固定软对齐结构属于未对齐各组共有的输入处理，不计作新增G模块。

推荐损失定义：设p^f、p^m为同一样本完整、缺失视图分类分布，r^f、r^m为原始强度预测，sg表示停止梯度，D为本次人为删去且原先可观测的槽集合。

\[
\mathcal L_C=\mathrm{KL}(\mathrm{sg}(p^f)\Vert p^m)
+\eta\,\mathrm{Huber}(r^m,\mathrm{sg}(r^f)),\qquad
\mathcal L=\mathcal L_{base}+\lambda_C\mathcal L_C+\lambda_R\mathcal L_R.
\]

\[
\mathcal L_R=\frac1{|D|}\sum_{(m,t)\in D}
\mathrm{Huber}\!\left(\hat h_{mt}/s_{mt},\mathrm{sg}(h^f_{mt})/s_{mt}\right),
\quad s_{mt}=\max(\mathrm{RMS}(\mathrm{sg}(h^f_{mt})),\epsilon).
\]

D为空时该项为零。对齐模型可在共享投影后的槽空间比较；未对齐模型建议在各模态原生50/500/500轴投影空间重构，再接软对齐。以完整视图为目标只用于训练监督和离线分析，禁止送入缺失测试分支。上述是待实现的受控方案，而非对当前代码能力的描述。

## 二、统一统计与绘图约定

- 按用户指定，主报告对齐使用2027/2028/2035，未对齐使用2026/2031/2033。每个布局的六组统一使用该布局的三个seed，不因某组结果更好而另换seed；其余历史seed仅作补充，不能混入主均值。训练seed与缺失掩码seed是不同层级，不能把三个掩码重复当作三个独立训练实验。
- 完整test固定727条。主评估网格为7种缺失集合T/A/V/TA/TV/AV/TAV × 6个跨度10/20/30/40/50/70% ×（起始/中间/末尾＋3次随机位置）＝252场景。T、A、V分别为文本、音频、视觉。
- 掩码seed固定5026/5027/5028；固定位置不重复计数。每个场景各模型共享样本ID与完全相同的掩码。对齐用共同时间槽；未对齐用各模态有效长度上的同一相对时间区间，称“相对时间位置”，不声称是秒级精确同步。记录标称跨度和实际删除观测比例，保留至少一个可观测位置，禁止局部缺失悄然变成整模态缺失。
- 主图默认30%跨度，对每seed先平均随机位置的三次重复，再对四个位置等权，再对七个缺失集合等权。跨seed报告均值±样本标准差（n=3，ddof=1，分母为2）。每个差值先在相同seed、场景配对计算，再汇总。
- 若主图聚焦对齐，未对齐用同版式独立面板或附录重画；不能合并两类输入得一个误差条。
- ACC、Macro-F1越高越好，强度MAE越低越好；MAE统一采用原始回归输出，若另报极性投影后强度必须单列并标注。稳定性也用原始回归值，避免后处理制造一致性。
- 颜色固定：B_full灰、B_miss橙、G蓝、C绿、R紫、ALL红；统一模型排序，兼用点形与线型，避免只靠颜色。输出矢量PDF/SVG及300dpi PNG；字体和坐标单位统一。不画3D柱图，不用雷达图混合不同尺度指标。
- 本文图注模板中的〔数值〕、〔最佳组〕必须由真实结果填写；若不支持预期，图注结论应改写，不删去反例。三seed误差条是描述性离散程度，不等同于95%置信区间。


### 指定seed的报告边界

对齐：2027、2028、2035；未对齐：2026、2031、2033。所有图注通用补充句：**“结果使用指定的三个训练种子（对齐2027/2028/2035；未对齐2026/2031/2033），误差条为样本标准差（n=3，ddof=1）。”** 单独绘制某布局时只写对应的三个seed。

这些seed在查看历史结果后被指定，因此需要如实称为“指定seed子集的描述性结果”，不能宣称是未经筛选的随机重复试验，也不能据此证明总体方差降低。不得把这组三seed标准差与此前五seed标准差直接作稳定性优劣结论。对齐/未对齐seed集合不同，跨布局比较不做按seed配对检验；同一布局内的模型比较则可以配对。新六组矩阵仍需每组在三个指定seed上重新训练或核验同协议结果，不能将旧拆除消融记录改名复用。

## 三、主图（4张）

### 图1：总体性能及单模块增益

**类型与标题**：三面板点区间图＋配对增益小面板；《连续局部缺失下的六组消融性能比较》。

**坐标/内容**：前三面板横轴六组，纵轴分别ACC（%）、Macro-F1（%）、强度MAE；展示每seed细小散点、跨seed均值与±1SD。第四面板横轴G/C/R/ALL，纵轴相对B_miss的ACC增益（百分点），零线贯穿；B_full灰色标记注明“完整输入参考”。

**图注（可直接用于论文）**：
> 图1 连续局部模态缺失下的六组消融结果。B_full与B_miss使用同一基线权重，分别接收完整输入和缺失输入；G、C、R、ALL分别启用门控、一致性约束、隐空间重构及三者组合。缺失跨度为有效时间范围的30%，每个训练seed内先平均随机位置的三次掩码重复，再对起始、中间、末尾、随机四种位置及七种缺失模态组合等权平均。小点为三个指定训练seed，中心点与误差条为均值±样本标准差。前三面板分别报告ACC、Macro-F1和原始强度MAE；第四面板为同seed配对的ACC差值，单位为百分点。B_full为完整信息参考，不参与缺失场景的增益排序。完整到缺失的性能变化为〔数值〕，各模块及组合的增益见图；误差条不代表显著性检验。

**论证目标**：分开量化信息缺失损失、单模块收益和联合性能，同时防止ACC提升掩盖少数类或强度预测退步。不能从ALL最高直接推导“三模块存在协同”。

### 图2：缺失时长—性能曲线

**类型与标题**：双面板折线＋标准差阴影；《模型性能随连续缺失时长的变化》。

**坐标/内容**：横轴标称缺失跨度10–70%，左纵轴ACC（%），右纵轴原始强度MAE；五条缺失模型曲线，B_full用水平灰虚线加独立参考带。另标各跨度实际删除比例的均值。每条线每个跨度按上述等权规则汇总。

**图注**：
> 图2 连续缺失时长对极性和强度预测的影响。横轴为缺失区间占模态有效时间范围的比例，而非整个模态删除概率；有效长度取整和保留观测规则会使实际删除比例略有偏差，实际比例随图附表给出。各曲线使用同一组冻结权重，在六个跨度、七个模态组合和四类位置上评估，随机位置重复三次。实线与阴影分别为三个指定训练seed的均值和±1样本标准差。灰虚线为同一完整输入基线的参考性能，并非该基线在各缺失跨度下重新评估的结果。曲线用于比较绝对性能与随时长增加的退化趋势；必要时另报告相对于各模型自身完整输入的下降量。

**论证目标**：模块收益是否只出现在轻度缺失；严重缺失下是否仍有效。曲线下降更慢不必然意味着绝对性能更好，两者分别描述。

### 图4：预测稳定性与一致性约束

**类型与标题**：双面板配对散点/点区间图；《完整—缺失预测的一致性与准确性》。

**坐标/内容**：左图横轴五个缺失模型，纵轴完整→缺失的类别翻转率（%）；右图横轴同样模型，纵轴平均绝对强度漂移。小点每seed，重点连线B_miss→C；图旁同时标记两组ACC差值，防止稳定但错误的模型被奖励。分类分布JS散度作为附表，不堆进同一量纲轴。

**图注**：
> 图4 同一模型在完整和缺失输入下的预测稳定性。对每条测试样本分别得到完整输入预测和30%局部缺失预测，类别翻转率为二者预测类别不同的比例，强度漂移为原始回归预测绝对差的平均值。五个缺失模型均以各自权重的完整输入输出为参照，而非统一用B_full输出作参照。场景聚合与图1一致，小点为训练seed，误差条为±1样本标准差。B_miss与C之间的连线表示同seed比较，旁注同步报告准确率变化。较低漂移只说明输出更稳定，只有同时保有准确率时才能解释为有益的一致性。

**论证目标**：一致性约束是否减少缺失扰动导致的预测漂移，而非输出恒定类别导致的虚假稳定。

## 四、辅助分析图（4张）

### 图5：隐空间补偿的定量质量

**类型与标题**：按模态分面的误差曲线；《人为缺失槽上的隐空间重构质量》。

**坐标/内容**：横轴六个缺失跨度，纵轴尺度归一化重构误差；分别画T/A/V面板，对比零填充、线性插值、R、ALL，附余弦相似度面板。全部方法在相同目标槽上比较。插值只读剩余观测，边界使用最近观测，不调用删去值；无可插值目标时记录而不静默剔除。

**图注**：
> 图5 隐空间补偿在人工删除位置上的质量。评分集合仅包含原本可观测、随后由评估掩码删除的槽，不包含padding及原始无效槽。目标为完整视图的投影特征，完整视图只用于离线评分，不参与缺失输入推理；每个学习模型使用自身完整视图特征作目标，零填充和插值在同一模型目标空间内构建。误差先按目标特征的RMS归一化，再在每个模态内聚合；接近零范数的目标使用预先固定的ε保护。实线与误差带为三seed均值±样本标准差。未对齐数据分别在原生文本50槽、音频500帧、视觉500帧的投影空间评价，不能把50槽输出直接与500帧真值比较。由于不同模型的表示空间仍可能变化，跨模型误差仅作诊断，不能单独证明情感预测信息已被恢复。

**论证目标**：重构是否优于简单填充，误差如何随时长和模态变化。与图1的任务收益联合解释；不使用t-SNE簇更紧作为重构成功证据。
