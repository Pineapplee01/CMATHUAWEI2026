# problem2_retrain：未对齐 50/500/500 软注意力

与正式 `problem2` 同方案，落在重训沙箱。数据只读：`AAAdata/Appendix_2/标准化/未对齐版本/processed_po`（不改磁盘 NPZ）。

## 500 序列怎么处理（核心）

**不池化、不插值到 50。** 音视保持原生 500 槽；文本仍是 50。

| 步骤 | 做法 |
|------|------|
| 读入 | `P_T/O_T (N,50)`，`P_A/O_A`、`P_V/O_V (N,500)`；`XA/XV` 已按 train-O z-score |
| 编码 | 文本在线 BERT（全量微调）；音视直接用已标准化特征 |
| 投影 | 各自投到 d=96，加**独立**位置嵌入（50 与 500 两套，不假设同下标对齐） |
| 连接 | 每词一段**连续局部窗**（中心单调、可重叠）→ **窗内内容软注意力**（softmax，非硬平均） |
| 缺失 | 连续挖洞在各模态自己的轴上：文本按 50，音视按 500 |

对齐 F1 那套「共享 50 轴 + CLS/SEP 上音视 P=0」**不适用于**本分支（音视与文本不在同一轴）。

## 训练

```bash
conda activate CPMCM
cd /user_home/gaojianan/CPMCM
python run_problem2_retrain.py \
  --config configs/problem2_retrain_unaligned.json \
  --seed 2026 \
  --run-name retrain_unaligned_soft_attention_seed2026
```

权重写入 `AAAmodel/checkpoints/runs/<run_name>/retrain_*.pt`（`format=unaligned_v1`），结果在 `problem2_retrain/results/unaligned/runs/<run_name>/`，诊断图在 `problem2_retrain/figures/unaligned/<run_name>/`。训练后报告**完整 test**；未对齐分支**暂不输出**局部 30% test Acc。
