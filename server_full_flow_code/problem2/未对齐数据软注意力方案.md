# 问题二：未对齐数据的软注意力加权融合

## 数据与运行入口

使用用户提供的 `AAAdata/Appendix_2/标准化/未对齐版本/processed_po`。文本为50×768、音频500×74、视觉500×35；各自保存P_T/O_T、P_A/O_A、P_V/O_V。P为有效范围，O为观测。音视频不压成50槽、不插值成相同长度，也不重复标准化。每种模态的500是存储上限，有效长度与可观测槽仍由掩码决定。

唯一总入口仍为根目录run_problem2.py：

```bash
conda activate CPMCM
# 单seed：训练→valid选epoch→完整test（未对齐暂不报局部30%）→诊断图
python run_problem2.py --mode train --config configs/problem2_unaligned.json --seed 2026 --run-name unaligned_soft_attention_seed2026

# 自选五个seed，每个seed独立训练和评估，结果明确记录seed
python run_problem2.py --mode train --config configs/problem2_unaligned.json --seeds 2026 2027 2028 2029 2030 --run-name unaligned_five_seeds

# 中断后恢复保存的配置；已完成实验跳过，未完成训练从头重跑
python run_problem2.py --mode train --resume problem2/results/runs/unaligned_soft_attention_seed2026
```

相同run-name不覆盖。配置提供的是架构与训练预算；实际checkpoint写入 `AAAmodel/checkpoints/runs/<run_name>/processed_po_seed<seed>.pt`，而不是配置中的示意目标路径。结果写入 `problem2/results/runs/<run_name>/`；每个seed目录中包含验证结果、完整/局部test预测、`test_scenarios/`的252组指标与实际掩码。

现有对齐模型的正式权重保持不变。新数据与新架构作为独立实验，不直接加载对齐模型任务头，也不混用对齐版的数据根目录。默认完整流程仍评估已有正式权重；未对齐实验使用本页明确的训练配置。

## 50、500、500如何连接

文本先按观测掩码遮蔽，再经过本地通用BERT在线编码。保留全量BERT微调，CLS/SEP参与编码结构，但其输出不另接全局分支。在线生成的文本隐藏态只应用一次未对齐train的文本scaler；音视频直接使用用户已标准化特征。

分别投影到d=96：

\[
E_T\in\mathbb R^{50\times d},\quad E_A,E_V\in\mathbb R^{500\times d}.
\]

投影前后均应用观测掩码，防止缺失槽的投影偏置被当作观测。独立位置嵌入保留各自序列顺序，不假设第t个音频帧对应第t个文本词元。

文本侧构造50个查询：

\[
Q=\operatorname{LN}(E_T+\mathrm{Pos}_T).
\]

**不是**对全部 500 帧做无约束全局软注意力。每个词槽先预测一段连续局部窗 \([L_t,R_t]\)（可重叠），且窗中心随词序单调非降；再在窗内做内容软注意力（保留 softmax，不是硬取均值）：

\[
s_{t,j}=\frac{q_t^\top k_j}{\sqrt{d_h}}-\lambda_t\cdot\frac{|j-c_t|}{T},\quad
A_{t,j}=\operatorname{softmax}_{j\in[L_t,R_t]\cap O}\,(s_{t,j}).
\]

窗外帧屏蔽（权重为 0）；导出矩阵仍是 50×500，但支撑集是连续局部段。相邻词可共享同一段音/视窗。null key 仅在整模态或该词窗内无观测时开放。

这是**学习到的局部软对应**，不等于真实时间戳。A/V 先分别连文本查询，再经融合层交互。

## 加权融合与预测

三个观测比例为r_T、r_A、r_V。对每个文本查询位置，拼接文本、软对齐音频和软对齐视觉：

\[
H_t=\operatorname{MLP}([E_{T,t};Z_{A,t};Z_{V,t};r_T;r_A;r_V]),
\quad a_t=\operatorname{softmax}_{t\in P_T}(w^\top H_t+b),
\quad z=\sum_ta_tH_t.
\]

最终预测头接收[z;r_T;r_A;r_V]，输出3维极性logits及1维强度，强度经3tanh限制在[-3,3]；提交强度仍按预测极性投影，另存原始回归值。

局部文本缺失时保留该位置的查询锚点，但词元内容不进入BERT或查询。若整条文本没有有效范围，而音视频仍有观测，则启用50个纯位置查询读取音视频；三模态全空时输出有限的先验预测，不声称具有可靠证据。

## 训练、评估与科学口径

保留全量BERT微调、类别平衡β=0.25、中性边界最大λ=0.1及原有分类/强度/有序损失。默认BERT学习率1e-5、其余1e-4，微批16累积4，最多12轮、patience4。从通用BERT和随机融合层起步，不迁移历史对齐融合初始化，所以与已有对齐模型的成绩差异不能归因于单个注意力模块。

train完整/局部缺失视图参与训练；valid完整与TAV30% ACC按70/30组合选epoch。每个模态在自身有效轴上产生连续缺失区间：文本在50槽轴，音视频在500槽轴。相同比例不表示删除相同槽数，也不意味着同步物理时间段。保留至少一个原观测，不以局部缺失模拟整模态删除。

冻结检查点后报告完整test；未对齐分支暂不把局部30% test 作为正式输出。场景网格与注意力诊断图按入口配置另行导出。所有结果记录训练seed；掩码seed与训练seed是不同概念。
