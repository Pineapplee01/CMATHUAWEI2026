# 问题一 v2：WordPiece + MFA 整词时间（同词子词共享）+ 音视加权聚合

## 流程

1. **MFA** 强制对齐 → 口语词区间 \(I_m=[s_m,e_m)\)  
2. **BERT WordPiece** 固定 50 槽；内容子词经字符重叠继承所属整词时间  
   - 同一口语词拆成的多个子词 → **共享同一** \([s,e)\)  
3. **音/视**：源帧 → `common_hop=0.04` → 对每个有时间的词元窗做**交叠时长 × 质量**加权均值  

因此相邻子词槽上音频（及有效视觉）相同是**预期行为**，不是随机撞车。  
`[CLS]`/`[SEP]`/`[PAD]`、无词时间的标点：无时间窗，音视置零。

MFA 失败：保留样本，时间与音视置零，记 `alignment_failure`。

## 与旧等分窗的差别

旧：音视进等分 \(B_k\)，文本独立 WordPiece。  
现：三模态都以 **WordPiece 槽**为轴；时间来自 MFA 词窗（非等分、非弱均匀摊）。
