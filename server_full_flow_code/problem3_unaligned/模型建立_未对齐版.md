# 问题三 · 未对齐版解释方法与评估指标

## 1. 方法概述

未对齐设定下，文本序列长度至多 $L_T=50$，音、视至多 $L_A=L_V=500$，三轴**互不共用下标**，也不将音视池化或插值到 50。问题三同样**不另训预测网络**，复用问题二已冻结的 SoftAlignment（单调局部窗软注意力将音/视软对齐到文本词轴后融合预测），输入掩码与标准化见 [../problem3/数据预处理说明.md](../problem3/数据预处理说明.md)。

完整前向下得到 logit $s\in\mathbb{R}^{3}$，本样本预测类 $c^{\star}=\arg\max_c s_c$ 在解释全程固定。相对对齐版，本文解释层在分轴表示上操作，并增加 soft association 将音视关键段回投到文本词。问题三**不新建预测模型**。内容分为：（甲）解释方法——（1）正向 Grad×Input；（2）多上下文边际贡献；（3）连续关键证据；（4）Soft association 关联；（乙）评估指标——Comp/Suff 与 Stab。对齐版方法见 [../problem3/模型建立_对齐版.md](../problem3/模型建立_对齐版.md)。

---

## 2. 符号约定

| 符号 | 含义 |
|------|------|
| $m\in\{T,A,V\}$ | 文本 / 音频 / 视觉 |
| $L_T\le 50$，$L_A,L_V\le 500$ | 各轴长度上限；有效长度由该轴 $P_m$ 决定 |
| $P_{m,t},O_{m,t},B_{m,t}$ | 分轴有效轴、原观测、解释干预 |
| $M_{m,t}=P_{m,t}O_{m,t}B_{m,t}$ | 分轴可读位 |
| $X'_m$ | 已标准化输入（文本为在线 BERT 隐状态再经文本 scaler；音视为一次 z-score） |
| $U_{m,t}=M_{m,t}X'_{m,t}$ | 投影前叶节点，未对齐 Grad×Input 的作用点 |
| $H_{m,t}=\mathrm{Project}_m(U_{m,t})\,M_{m,t}$ | 投影后表示，进入 soft cross-attn 与融合 |
| $A^{T\leftarrow A},A^{T\leftarrow V}\in\mathbb{R}^{50\times 500}$ | 文本←音/视 soft 注意力（对多头取平均），$A_{ij}$ 为文本槽 $i$ 对音/视槽 $j$ 的权重 |
| $s,\ p(c),\ \hat y$ | 分类 logit、类概率、强度 |
| $c^{\star}$ | 冻结预测类 |
| $r_{m,t},\ I_m,\ \tilde\phi_m,\ E_m$ | 与对齐版同义的正向归因、模态占比、边际贡献、证据槽集 |
| $\eta,K,\sigma,R$ | 证据质量、关联 TopK、Stab 噪声、Stab 重复；默认 $0.7$、$5$、$0.01$、$3$ |

因三轴分立，关模态与挖洞均在**该轴自身下标**上操作，不再假设「文本第 $t$ 槽 = 音视第 $t$ 帧」。

---

## 3. 正向 Grad×Input 归因方法

**目的。** 在各轴原始特征尺度上估计对 $c^{\star}$ 的正向支持，得到可按 $50/500/500$ 分别画曲线的槽级质量。

叶节点取投影前的 $U_m$（而非对齐版的补全前投影表示）。对 $s_{c^{\star}}$ 反传，

$$
\tilde r_{m,t}
=
\sum_{j}
U_{m,t,j}\,
\frac{\partial s_{c^{\star}}}{\partial U_{m,t,j}},
\qquad
r_{m,t}
=
\max\bigl(0,\tilde r_{m,t}\bigr)\,
\mathbf{1}[M_{m,t}=1].
$$

$\tilde r_{m,t}$ 的符号含义与对齐版相同：正为支持 $c^{\star}$，负为抑制；解释只保留前者。模态内部归因

$$
G_m=\sum_{t} r_{m,t},
\qquad
I_m=\frac{G_m}{G_T+G_A+G_V}
\quad\bigl(\text{分母为 }0\text{ 则 }I=\mathbf{0}\bigr),
\qquad
m_{\mathrm{sens}}=\arg\max_m I_m.
$$

其中 $s$ 由 SoftAlignment 前向给出：各轴投影后，经单调窗 soft cross-attn 得到对齐到文本词轴的音/视表示，再融合、池化并经分类头输出。$I_m$ 仍为正向质量占比，不作因果解读。

---

## 4. 多上下文边际贡献方法

**目的。** 在分轴设定下，从输出侧估计各模态对 $p(c^{\star})$ 的平均边际效应。

视图族与配对集 $U_T,U_A,U_V$ 与对齐版相同。两点差异：

1. **关模态**：将模态 $m$ 对应轴的 $O_m$ **整段**置零，而不是在共享 50 槽上挖洞；
2. **可用性**：$\mathrm{avail}_m=\mathbf{1}[\exists t:\,O_{m,t}=1]$，不再与 $P_m$ 求交。

对两端均成功计算的配对子集 $U_m^{\mathrm{ok}}$，

$$
\tilde\phi_m^{p}
=
\frac{1}{|U_m^{\mathrm{ok}}|}
\sum_{(S^{+},S^{-})\in U_m^{\mathrm{ok}}}
\bigl(
p(c^{\star}\mid X^{(S^{+})})
-
p(c^{\star}\mid X^{(S^{-})})
\bigr).
$$

$\tilde\phi_m^{y}$ 将概率换为强度同理。主要参考模态 $m^{\star}=\arg\max_m\tilde\phi_m^{p}$，要求最大值严格为正。完整视图记 $p_0=p(c^{\star}\mid X^{(TAV)})$、$y_0=\hat y(X^{(TAV)})$。

---

## 5. 连续关键证据抽取方法

**目的。** 在各轴上把正向质量压缩为连续区间，供解释卡与删除复核使用。

算法与对齐版相同：按 $r_{m,t}$ 降序贪心，累计 $r_{m,t}/R_m$ 至不少于 $\eta$，填缝后合并为 $\mathcal{S}_m=\{[\ell,h)\}$，得 $E_m$。因轴长不同，有

$$
E_T\subset\{0,\ldots,49\},
\qquad
E_A,E_V\subset\{0,\ldots,499\}.
$$

对 $[\ell,h)\in\mathcal{S}_m$ 做片段复核时，仅将**该轴** $O_m[\ell:h)$ 置零，再计算 $\Delta^{p}=p_0-p'(c^{\star})$ 与 $\Delta^{y}=|y_0-y'|$。文本证据可用强制对齐词级时间写出时段；音视若无已核实的特征级时标，则**禁止**使用均匀映射 $t\mapsto (t/L)\times$ 时长，可改用第 7 节 soft association 关联到文本词后再挂时间。

## 6. 评估指标

与对齐版相同，用事后指标检验关键证据的保真与稳健性；均不改变原预测。Stab **不**在 soft association 边集上计算。

### 6.1 保真度 Comp / Suff

联合三轴关键证据，检验其对 $c^{\star}$ 概率的必要性与近似充分性。在全部关键段上构造删证据输入 $X^{\mathrm{rm}}$ 与只留证据输入 $X^{\mathrm{keep}}$（各轴按自身 $E_m$ 改 $O_m$），定义

$$
\mathrm{Comp}=p_0-p(c^{\star}\mid X^{\mathrm{rm}}),
\qquad
\mathrm{Suff}=\lvert p(c^{\star}\mid X^{\mathrm{keep}})-p_0\rvert.
$$

$\mathrm{Comp}$ 大表示关键窗更必要，$\mathrm{Suff}$ 小表示仅留关键窗时更接近完整输入。

### 6.2 稳定性 Stab

检验分轴证据窗对音视观测小噪声是否稳定。基线 $\{E_m\}$ 由未扰动输入经第 3、5 节得到。对 $r=1,\ldots,R$，仅在 $O_A,O_V$ 为 1 的位置对 $X_A,X_V$ 加 $\mathcal{N}(0,\sigma^{2})$ 噪声，文本不变；重算各轴 $E_m^{(r)}$，对证据槽集合取 Jaccard 并平均：

$$
\mathrm{Stab}
=
\frac{1}{3R}
\sum_{r=1}^{R}
\sum_{m\in\{T,A,V\}}
\frac{\lvert E_m\cap E_m^{(r)}\rvert}{\max\bigl(1,\lvert E_m\cup E_m^{(r)}\rvert\bigr)}.
$$

## 7. Soft association 关联方法

**目的。** 未对齐下音视槽与文本词无天然同下标，需要利用 SoftAlignment 学到的注意力，把音视关键段解释回文本词轴，便于口头描述与时间锚定。

取融合阶段的 soft cross-attn，对多头平均得到 $A^{T\leftarrow A}$、$A^{T\leftarrow V}$。对音频关键区间族 $\mathcal{S}_A$，定义文本槽 $i$ 从音频证据获得的关联质量

$$
q_i^{A}
=
\sum_{[\ell,h)\in\mathcal{S}_A}
\sum_{j=\ell}^{h-1}
A^{T\leftarrow A}_{ij}.
$$

再取正质量上的 Top-$K$ 文本槽作为音频证据的文本关联集：

$$
E_T^{(A)}
=
\mathrm{TopK}_{i}\bigl(q_i^{A};K\bigr)
\cap
\{i:q_i^{A}>0\}.
$$

视觉同理，由 $A^{T\leftarrow V}$ 与 $\mathcal{S}_V$ 得到 $q_i^{V}$ 与 $E_T^{(V)}$。$E_T^{(A)}$、$E_T^{(V)}$ 是**模型内部软关联**，表示「网络在预测时把这些音/视段主要对应到哪些词」，不能等同于物理时间对齐或人工标注的音视频同步。

---

## 8. 与对齐版的差异及小结

| 项目 | 对齐版 | 未对齐版 |
|------|--------|----------|
| 时间轴 | 共享 $L\le 50$ | $50/500/500$ 分立 |
| Grad 叶节点 | 补全前投影表示 $E$ | 投影前叶 $U$ |
| 关模态 / 可用性 | 共享槽上改 $O$；$(O\wedge P).\mathrm{any}$ | 整轴清 $O_m$；$O.\mathrm{any}$ |
| Soft association | 无 | 有 |

未对齐设定在冻结 SoftAlignment 上用解释方法得到各轴 $r_{m,t}$、$I_m$、$\tilde\phi_m$、$E_m$，并用 soft association 将音视证据关联到文本词；Comp/Suff 与 Stab 仅作评估，不是另训模型。全程不更新参数，不改变原预测。
