# 问题一 v3 采用说明（方案A / MFA，已接通）

## 定位

**MFA 词级强制对齐**：音、视、文本内容均聚到词区间 $I_k$，不是等分 50 时间窗。  
对齐代码：`mfa_alignment/`；**不含 `[CLS]`/`[SEP]`**（词槽 = 转写内容词；`view50` 取前 50 词，超长截断）。  
音视源帧先统一到 `common_hop_sec=0.04` 再聚到 $I_k$。  
文本细节：[BERT文本特征说明](BERT文本特征说明.md)；时间轴：[统一时间戳—+标准化](统一时间戳—+标准化)。

## 流水线

```
转写 → words_of → MFA → I_k
BERT(按词；词内 WordPiece 均值) / COVAREP / OpenFace AU
→ 音视 unify_modality(hop=0.04) → aggregate 到 I_k → view50 → (N,50,d)
```

入口：`python -m problem1_v3.problem1 extract`

## 产出

默认目录 `problem1_v3/results/`：

| 文件 | 形状/内容 |
|------|-----------|
| `text_features.npz` | `(N,50,768)` 词级 BERT |
| `audio_features.npz` | `(N,50,74)` COVAREP→词 |
| `vision_features.npz` | `(N,50,35)` AU→词 |
| `intervals.npz` | `(N,50,2)` 每词槽起止秒 $[t_0,t_1)$（MFA 词边界；无词槽为 0） |
| `masks.npz` | mask + `word_support` |
| `alignment_manifest.csv` | MFA 成功/失败记录（无均分回退） |

```bash
conda activate CPMCM
python -m problem1_v3.problem1 extract --limit 1
```
