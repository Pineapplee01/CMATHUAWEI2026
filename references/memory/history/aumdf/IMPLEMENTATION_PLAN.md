# AUMDF赛题数据适配复现计划

目标：在本目录独立实现论文网络与教师—学生蒸馏，以附件2对齐特征验证，不宣称复现完整MOSEI的论文成绩。用户已确认使用赛题数据适配。

## 实现与验收

- [x] 模型：REM双BiLSTM、均值方差归一化、门控噪声补偿；RPM卷积位置编码；DWAM双模态门控；三路Q/K/V不同模态的MMT；池化及回归/七分类读出。
- [x] 损失：6个方向的同极性跨模态CSD；投影后余弦SRD；Q/K/V参数正则；教师冻结与梯度隔离测试。
- [x] 数据：只从项目data/加载附件2；完整保留划分与样本；训练集拟合缩放参数；分离填充与观测掩码。
- [x] 缺失：论文式逐位置随机缺失；另提供明确标记的连续区间适配及整模态评估，不混称同一实验。
- [x] 训练：完整输入教师，再冻结教师训练学生；配置、审计、检查点、逐轮日志均保存至artifacts/aumdf；验证集选优。
- [x] 验证：单元测试，CPU/GPU前向反向，真实数据小规模两阶段训练与检查点重载，完整两阶段训练。
- [x] 交付：README、来源/公式映射、未报告细节与适配选择、真实运行报告。保持其他参考算法不变。

## 固定实现选择

默认aligned_50，三模态768/74/35；隐藏表示300，每BiLSTM方向150；注意力6头、1层、卷积核3；dropout=0.8；Adam lr=0.001；教师、学生各最多20轮，patience=20；批量32、种子2026；3项损失外部系数0.1，内部QKV系数1e-4。论文未报告的量将于REPRODUCTION.md逐项注明。

默认L1回归及验证集校准中性阈值；另提供七分类CE及期望强度读出。Eq.22的时间矩阵不能直接加到特征矩阵，采用窗口内距离注意力偏置；padding在softmax前屏蔽。Eq.39的逐元素积归约为余弦内积。教师先独立监督训练，学生默认独立初始化。
