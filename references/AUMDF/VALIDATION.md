# AUMDF实际验证记录

日期：2026-09-23。结论：独立赛题适配实现通过测试，并完成一次完整的教师—学生训练和固定检查点评估。**不等同严格复现原论文成绩，也不证明优于其他基线。**

## 1. 数据、设备与训练范围

- 数据：附件2 aligned_50.pkl；train=3395、valid=728、test=727；没有重新划分。
- 数据SHA-256：`66e867aa74bc70a844e806e5571e371c9abb4a35f9e2887ce9b4d97ff2cb8fcd`。
- 训练输入维度：文本768、语音74、视觉35，各50步。
- 实际环境：Python 3.12.3、PyTorch 2.5.1、NumPy 1.26.4、CUDA 11.8。
- 设备：NVIDIA GeForce RTX 4060 Laptop GPU；独立网络参数数=8,614,504。
- 随机种子：2026。教师20轮，学生20轮；记录训练阶段总用时约24.41分钟。
- 学生采用随机位置缺失训练，p从0.1–0.7抽取；连续区间缺失仅作为本次固定模型的迁移压力测试。
- 只使用验证集选模型与中性阈值；测试集从未用于checkpoint选择、阈值调整或重训练。

## 2. 已执行的验证

1. 本目录15项pytest测试：模型前向／反向、padding不变性、全缺失有限性、时间窗口、CSD空正例、SRD、冻结教师、数据路径边界、训练集缩放、三分类指标、两阶段训练、smoke／完整训练来源标识。
2. 原项目12项测试通过，未修改其他参考模型。
3. CUDA真实数据smoke：64条train、32条valid，每阶段1轮；结果标为smoke_only，不作为质量结论。
4. 完整真实数据：20+20轮，共40条epoch日志；所有损失均为有限值。
5. 最优checkpoint重载，并在727条test上评估15个条件；每个条件保留727个唯一样本ID。
6. 独立指标交叉核对：15个条件的MAE、Accuracy、Macro-F1、Weighted-F1与scikit-learn一致，Pearson与NumPy一致，绝对差小于1e-12。
7. CodeGraph可以检索AUMDF模型及其数据、损失和训练依赖。
8. 独立只读审查发现的smoke来源标识丢失问题，已通过先失败后通过的回归测试修复。本次早期生成的checkpoint已补入scope和使用样本数，逐个模型张量确认未改变。

测试命令：

```powershell
python -m pytest -c references/AUMDF/pyproject.toml references/AUMDF/tests -q
python -m pytest tests -q
```
