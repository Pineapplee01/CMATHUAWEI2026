# 论文到代码的映射与适配边界

## 来源与复现目标

- 论文：王楠、王淇、欧阳丹彤，《基于知识蒸馏与动态调整机制的多模态情感分析模型》，计算机学报48(8)，2025，1923–1942。
- 英文框架名：Attention-based Uncertain Missing Modality Distillation Framework（AUMDF）。
- DOI：10.11897/SP.J.1016.2025.01923。
- 实际来源：用户提供的PDF；SHA-256为 `b059c680a1b5f69b011f6e62cf417c7aecc9f9523bdf58ced8f332f51e640a1c`。
- 页码采用PDF中1-based页码；PDF p.6对应印刷页1928。已直接查看p.6–11的方法图与公式页面。
- 本文为**定向复现说明**，不是全篇逐图表审稿报告。GitHub按AUMDF及框架全称检索未定位可靠作者实现，故不宣称与作者代码逐行一致。
- 用户确认：使用E题数据适配复现。只训练附件2的3395条train，在728条valid上选择模型；727条test用于固定后的评估。

核心链：完整输入教师学习情感表示 → 随机缺失学生输入 → 动态门控与三模态注意力融合 → CSD/SRD传递教师表示 → 学生独立推理。

## 明确的差异、歧义及实现选择

以下不是原论文已报告事实，不能在论文中省略。

1. **输入特征不同。** 原文§4.2.1使用GloVe 300维、COVAREP 74维、MA-Net 1024维。此处使用附件2提供的768/74/35维，不重新下载外部情感训练数据，也不假装两套特征等价。
2. **序列长度冲突。** 原文§4.2.1写MOSEI/MOSI词级对齐为50步，表2却写文本25、音频150、视觉100。此处采用题目aligned_50的50/50/50，明确拒绝无声重采样unaligned输入。
3. **分类与回归冲突。** §3.1定义连续回归，式(34)/(41)却为Softmax/CE，未说明如何得到[-3,3]连续分数。默认采用线性回归头与L1；可选classification模式使用七级CE并以概率期望得到强度，这是另一项明确实现选择，不是作者已确认的解码规则。
4. **门控与拼接维度。** 式(12)的⊗和式(20)的点乘未完整说明维度。本实现REM两分支加权拼接；DWAM两个h/2门控拼接后与h维投影逐元素相乘。不能据此声称唯一还原了作者算子。
5. **噪声阈值。** 原文未给rho数值，式(9)用未加帽符号但正文称作用于激活向量；此处在ReLU激活后以0.1硬门控，补偿由过滤分支隐藏状态的时序均值和标准差产生。
6. **时间信息。** 式(21)定义T×T关系而式(22)将其加到T×d特征，未给映射。此处采用对称窗口abs(i-j)<=5及距离偏置-abs(i-j)/5，直接作用于注意力logits；没有声称恢复真实秒级时间戳。
7. **掩码修正。** 式(30)在softmax前乘0/1仍可能让填充位置获得非零概率。此处用负无穷等效屏蔽，并处理所有键都不可用时输出零，避免NaN或填充泄漏。
8. **三模态注意力。** 以图3和式(31)为可执行依据：文本Q、视觉K、语音V，其余模态循环置换。式(25)的三向量乘积是相似性动机，式(30)没有定义三维注意力张量，因此不额外杜撰立方张量算法。
9. **CSD索引歧义。** 式(35)–(37)的正样本索引与分母索引不够明确。按图1教师/学生间连线实现跨网络对比，每个锚点与另两模态的候选相似度加权求和。同极性且不同样本为正例，分母含其余所有样本；没有正例的锚点跳过，不强行制造正例。
10. **CSD数值尺度。** 对模态池化向量作L2归一化，再做点积；正的可学习缩放因子从1/0.07初始化，上限100。原文只说明可学习alpha，未报告初始化、温度或归一化，因此这些是稳定性选择。
11. **SRD归约。** 式(39)将⊙解释为逐元素乘法但损失应为标量；按图1的cos与相似性描述，将乘积沿特征维求和后计算余弦距离，投影为h维，alpha_st固定1。
12. **额外输入缩放。** 标准化原始特征只用train中有效且可观测位置拟合，参数进入检查点；valid/test不参与拟合。REM内部仍有独立的隐藏表示归一化。
13. **缺失与padding。** padding来自text_bert注意力掩码；全零数值行作为保守的不可观测指示，但不能证明所有零行均为人工缺失。观测掩码与padding掩码单独传递；模拟缺失后继续保留原padding信息。
14. **未给定超参数。** 批量32、每BiLSTM方向150（合计h=300）、6个注意力头、1层MMT、FFN宽度600、kernel3、epsilon=1e-5、梯度裁剪1、内部QKV系数1e-4均为实现选择。表2的h=300、lr=0.001、dropout=0.8、外部lambda=0.1和patience=20保留。
15. **两阶段轮次。** 原文给训练轮次20，未区分教师／学生。此处教师与学生各最多20轮，共最多40轮；学生默认独立初始化。不得把这解释为原论文确认的总预算。
16. **验证集选择。** 教师按clean-valid MAE选优；学生按clean-valid和固定p=0.3损坏valid的平均MAE选优。缺失方式与训练一致；每轮验证重置同一随机种子。原文未详细给出选优口径。
17. **三分类阈值。** 最佳模型确定后，仅用clean-valid Macro-F1在[0,0.5]步长0.01搜索对称中性区间；真实y=0单独属于中性。test与缺失评估沿用该固定阈值。
18. **平台不同。** 原文PyTorch1.8.2/V100，本次PyTorch2.5.1/4060 Laptop。控制随机种子、关闭cuDNN benchmark并启用deterministic；不承诺不同硬件逐位一致。
19. **评估读出。** 线性回归训练不裁剪，报告与导出统一裁剪到[-3,3]。Pearson常数输入返回null。七级指标采用NumPy round；该指标不是赛题三分类。

## 原生协议与赛题扩展

- 原生RPRM式训练：按批次从0.1到0.7选一个缺失率，三模态独立随机丢弃位置。
- 连续区间扩展：对每样本有效序列，丢弃round(length*rate)个连续位置；不把padding计为有效长度。这是按有效位置比例定义的长度，不等价于真实秒数。
- 整模态评估：保留七种非空模态组合，与原文表3/4的展示形式对应，但输入特征和数据划分不同，不直接比较数值。
- 默认训练没有混入连续区间增强。可另开block模式实验，不能把两者结果混成一次训练。
- 本次不生成附件3/4最终提交文件。附件3缺少预计算text，需先建立训练／推理一致的文本编码接口。
